# 漫剧样片《这一次，我不嫁了》第 1 集开头（37 秒）

频道主想做“书的解读”或“漫剧”，问我做的漫剧能到什么效果，所以做了这条样片。

- **剧情**：重生复仇。她死在婚礼那天，推她下去的是爱了七年的人；再睁眼回到三年前，他打电话约她，上辈子就是这晚求的婚。“这一次——”接片名《这一次，我不嫁了》，然后是下集预告和“关注我，看下一集”。
- **画面**：MiniMax 生成的韩漫风插画（`img/`）。
  - 女主先定一张设定图（`img/_女主设定.jpg`），后面三张用它当脸的参考，所以是同一个人。
  - 参考图的表情要平静，不然后面每张都跟着它的表情走（试过一张惊讶的当参考，结果张张都张着嘴）。
  - 写“semi-realistic”会画成真人照片，要写“2D anime illustration, Korean webtoon style”。
  - MiniMax 图片的下载地址（阿里云 OSS）在这个环境里连不上，所以图片要 base64 拿；1080×1920 的大图常常断，用默认的 9:16（720×1280）再放大。
  - MiniMax 的视频模型也是一样，生成的视频下载不下来，所以画面不能真的动，只能靠镜头和特效。
- **镜头和特效**（`scenes.js`，都是在画面代码里做的）：
  - 慢推、仰拍往上摇、心跳时画面一缩一放；
  - 雨、闪电、白光、黑场、上下眼皮张开的“睁眼”；
  - 手机锁屏（说到“三年前”时年份变红）、来电震动；
  - 推到脸上时画面变冷；片名砸出来带震动。
- **配音**：
  - 女主：`female-yujie-jingpin`（御姐），每句带情绪：悲、惊、怕、冷（`meta.json` 的 `voices`，一种情绪一个名字）；
  - 他：`male-qn-jingying-jingpin`（精英青年），做成电话里的声音（`python3 layout.py --phone`：只留 300–3400 Hz）。
  - 他的台词字幕是淡蓝色。
- **声音**：没有配乐，全是音效：雨、心跳、闪电、低音、上冲、白光的重击、戛然而止、吸气、早上的鸟、手机震动、片名的重击。

## 做法
```
python3 layout.py --prov && python3 ../tools/cine/tts.py . && python3 layout.py --phone && python3 layout.py
NODE_PATH=$(npm root -g) tools/make_cine.sh manju00 漫剧样片_这一次我不嫁了.mp4
```
