# 黑猫不说话 No.54《把自己捡回来》

照着频道主发来的参考视频做的一期：**主人公的独白**（画外音 + 画框下面的字幕），学那条视频的分镜和运镜。人物、背景、配音的写法照着 `talk10/`，新的地方如下。

## 镜头（`scenes.js`）
- **镜头表**（`SHOTS`）：
  - 每个镜头写成 `{ t0, f }`，`f(t, u, d)` 画这个镜头（`u` 是镜头开始以后的秒数，`d` 是镜头长度）；
  - 下一个镜头的 `t0` 就是这个镜头结束（切）；
  - 快切的镜头可以带一个细字 `word`，`wp` 是细字的位置。
- **取景**（`view` / `frame`）：写成 `[画框中心对着的点 x, y, 放大倍数, 转角]`，屏幕坐标。
  - 放大以后照片还是盖满画框（中心点会被夹住），不会露出黑边；
  - 一个镜头里用 `camLerp(a, b, k)` 从一个取景慢慢变到另一个。
- **主人公**（`hero`）：
  - 半身：`cx` 是脸，`top` 是帽子顶；
  - 全身：`feet` 是脚底，`hgt` 是身高，脚下有影子（路口的远景）；
  - 剪影：`sil`（窗前逆光，边上一圈橙色的光）；
  - `rot` / `pivot`：栽到床上；
  - `runner()`：跑步，一步一颠，往前倾一点。
- **路人**（`passers` / `PASS`）：别的角色的黑影，糊的，从镜头前快速走过去。开头第一个路人走过去的那一下，主人公出现在人潮里。
- **大字**（`BIG`）：一个个砸出来（一下放大再落定），一组说完一起消失。“跑步”两个字画在主人公**身后**（`runWord`，在照片和人物之间画）。
- **跑步**（`track`）：
  - 照片自己从放大慢慢缩回去，人物大小不变，看起来是镜头跟着他往后退；
  - `overtake()`：第一天背心男从旁边跑上来，越跑越近，出了画；
  - `sweat()`：甩出去的汗。
- **快放**（`replay`）：“第二天，再来一遍”时，把一天的六个镜头各放 0.22 秒（用原来的镜头函数，时间加快）。
- **插入镜头**：打卡、周报、群聊、短视频、闹钟、朋友圈、锁屏。快切里的手机小一点、放右边，左边留给细字。
- **黑场**（`BLACKS`）：每一项是 `[黑到底, 开始亮, 淡出用时, 淡入用时]`。
- **字幕**（`subtitles`）：`DIALOG` 里 kind 是 `vo` 的台词，一句一句显示在画框下面。
- **回忆**：教室那段用 `memoryLook`（跟 `talk10` 一样，整体泛黄、颗粒、轻轻闪）；黑板上的倒计时是画上去的。

## 时间轴（`layout.py`）
- 独白每一句写成 `['黑', 'vo', 台词, 停顿]`；
- 换段写成 `(段名, pad, lead)`；
- 快切那段停顿很短（0.15–0.2 秒），重要的话后面留白（2 秒左右）。

## 声音
- 新音效（`tools/cine/audio.py`）：`step`（脚步，`surface: 'track'` 是塑胶跑道）、`breath`（一口气，`heavy` 越大越喘）、`alarm`（手机闹钟）、`game`（打游戏的小音效）。
- `whoosh` 加了 `dir`：-1 是从右往左。
- 跑步的脚步落在身体颠到最低的时候（`k / cad`）。
