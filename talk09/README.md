# 黑猫不说话 No.52《电梯里遇到领导》

Wojak 叙事短剧，写法照着 `talk08/`。不同的地方如下。

## 场景
两场戏，一场一张背景图（都是 MiniMax 生成的），取景基本不动：

| 场景 | 背景 | 人物 |
|---|---|---|
| 电梯厅 | `lobby.jpg` | 主人公在左；门一开，领导出现在右边（淡入） |
| 电梯里 | `elevator.jpg` | 主人公在左，领导在右；八楼时老哥小一号，从两人中间的后面探出头；领导在十六楼往右走出去 |

两个人说话时面对面：领导、老哥原图都朝右，站在右边时左右翻过来（`person()`）。

## 电梯（都在 `scenes.js`）
- **时间表**（`STOPS()`）：每一站写成 `[到达, 楼层, 开门, 关门]`，时间挂在台词上（`D(i)` / `DE(i)`）。
  - 电梯厅：一直停在 18 楼，`D(1)` 之后一口气下到 1 楼，门开；
  - 电梯里：1 → 3（没人）→ 8（老哥）→ 16（领导下）→ 18。
- **`liftAt(t)`**：算出现在几楼、往哪走、门开着没有。
- **`floorDisplay`**：画框下面黑边里的红色楼层显示，走的时候箭头在闪；最后的字卡出来前淡出。
- **开门时**：画面中间稍微亮一点，像走廊的光照进来。
- **电量**：100% → 70% → 40%，掉两次。
- **音效**（`CUES`）：从同一张时间表生成每站的“叮”、开门声和关门声。

## 声音
- **配乐**（`music.py`）：只有电梯里有“电梯音乐”，声音做窄、做闷（只留 280–2800 Hz），−24 LUFS。
  - 领导说“下午开会你来讲讲”那一下突然停掉，领导出电梯后再接上；
  - 停和接是在成品上乘音量包络做的。
- **新音效**：`tools/cine/audio.py` 加了 `lift`（电梯运行的嗡嗡声）和 `doors`（电梯门）。

## 时间轴
- `layout.py` 的换段可以写成 `(段名, pad, lead)`：`lead` 是新一段开头空多久才说第一句。
- 这一期进电梯后先安静 2.6 秒，这段尴尬的沉默就是这么排出来的。
