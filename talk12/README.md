# 黑猫不说话 No.55《购物车里的游戏机》

照着频道主的“理想型”参考视频（《当一个男生的配得感越来越低》，剖析见 `refs/配得感/`）做的一期：**骨架和镜头学它，故事和台词自己写**。人物、背景、对话框、配音的写法照着 `talk10/`、`talk11/`，新的地方如下。

## 镜头（`scenes.js`）
- **镜头表**（`SHOTS`）：每个镜头写成 `sh(id, t0, f)`，`f(t, u, d)` 画这个镜头；下一个镜头的 `t0` 就是这个镜头结束。`id` 给回忆快闪用（`BYID`）。
- **机位**（`set`）：一个机位 = 照片 + 人，外面再乘镜头（`view` / `frame` / `camLerp`，跟 talk11 一样）。
  - 照片可以单独再放大一点（`z` / `at`）：拍单人时离得更近，人不跟着变大；
  - **景深**（`dof`）：叠一张糊的照片（`soft()`，只算一次）。拍单人时 0.45 左右，镜头推近（放大到 1.2 倍以上）时自动加。
- **背景跟着机位换**：出租屋是一张 2048×1024 的宽照片（`ROOM`）。两人同框用中间（`C`），拍她用右边（`R`，台灯、书桌），拍他用左边（`L`，沙发）。还是同一张图，光和颜色一定对得上。
- **过肩**（`otsMe` / `otsHer`）：前景的人压成黑影、糊的（`DARK`，亮度 0.06、糊 6 像素），占画面一侧四成；后景的人小、清楚。
- **嘴一张一合**：`layout.py` 按每句配音的响度量好（`MOUTH`，每秒 15 格，1 = 张嘴）。
  - 主人公：`HMOUTH` 是每个表情嘴的位置，张嘴时先用肤色盖住原来那条线，再画一个深色的小口（开心是“D”形）。
  - 其他人（半身像）：`CAST[key].mouth`。全身像人太小，不动嘴。
- **全身像**（`full`）：远景、过肩镜头的后景用（妈妈只有全身像；她在“生日前一周”第一个镜头站在书桌旁）。
- **对话框**：字放大到 44 像素；两行时在标点后断、两行差不多长（引擎的 `wrapRuns`）。主人公的在左边，别人的在右边；看得见说话的人才画尾巴（`SEEN` 记下这一帧画出来的人头顶在哪）。换段之前收掉。
- **时间小字**（`TIMES`）：画框上面的黑边，左边，“*大二暑假”“*他生日前一周”……
- **模糊转场**（`cutBlur`）：换段时 0.2 秒越来越糊，最糊的时候切，0.6 秒先快后慢地变清楚。做法是 `postFilter`：把画框那块拷出来，加滤镜再画回去。
- **回忆快闪**（`montage` / `montageSeq`）：照着参考视频逐帧量出来的节奏。
  - 前面镜头的画面（用原来的镜头函数），灰的；
  - 先 4 张，每张 0.11 秒、还是糊的 → 白光 → 一张 1–3 帧的快闪，中间夹白光 → 两张停得久一点、暗一点 → 又一串 → 最后一下白光；
  - 从白光里淡出**彩色的购物车**（开头那个画面），停一会儿，叠化到他的脸。
- **同一个画面用三次**：购物车（`cartScreen`）开头是“刚刚加入”，发工资那天“2个月前加入”，她看见的时候“5年前加入”。插入镜头推向那一件（`ITEM`），让“X 前加入”看得清。
- **手机界面**：银行短信、妈妈碎屏的旧手机（“微信”无响应）、商品页 → 支付成功、大字的聊天、账单、请帖和聊天、搜电饭煲 → 购物车、结算 → 付款面板 → 手指停在“立即支付”上发抖 → 支付成功。购物、付款这些界面是白的，冷冰冰的；**只有游戏机（`drawConsole`，橙和青）一直是饱和的暖色**。
- **电视**（`tvScreen`）：照片里的电视本来亮着，平时画成黑的；他生日那天在玩游戏（`pixelGame`），屋里有一闪一闪的光（`tvLight`）。

## 时间轴（`layout.py`）
- 对白每一句写成 `[谁, say/think/msg, 台词, 停顿]`；换段写成 `(段名, pad, lead)`；
- 新加了口型：每句配音按每秒 15 格量响度，写进 `MOUTH`。

## 声音
- 新音效（`tools/cine/audio.py`）：`whoomp`（模糊转场的低音“嗡”）、`impact`（回忆快闪白光的低音冲击）、`tone`（白光过后留下的长音）。
- 配乐（`music.py`）：很轻的钢琴，G 大调，一个高音（D6）一直轻轻重复；有台词时让开，没台词的地方出来；“为什么……”停，按下“立即支付”那一下落到 G 大调，结尾更亮、带旋律。
