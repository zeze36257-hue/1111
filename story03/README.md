# 动画讲故事 第 3 集：水门桥

11 月 8 日做的。**竖屏** 1080×1920，30 帧，约 4 分 3 秒。稿子、核对情况、来源见 `refs/讲故事/第3集_水门桥.md`。

频道主这一集的要求：
- 第 2 集平均只看了 8 秒，所以开头改了：第一帧就是炸断的桥 + 标题，旁白 0.3 秒开口说钩子（“这座桥，志愿军炸了三次。美军，却从天上，空投来了一座新桥。”）。
- 做成竖屏（他 11 月 8 日选的）：上面标题“抗美援朝 · 长津湖 / 水门桥 / 炸了三次，美军从天上空投了一座桥”，中间 16:9 的画面，下面字幕，进度条和仙人掌柜在画面底边。

## 怎么做的
1. **旁白**：`python3 tools/voice/narrate.py refs/讲故事/第3集_水门桥_旁白.txt <目录> --speed 0.86 --band 290,340 --asr <SenseVoice 目录>`
   - 49 句，全长 243 秒；每句 260～340 字/分钟。
   - 读音核对：46 句对上；3 句“兴南港”语音识别都听成“新南港”。试了不加读音词典、换成同音的“星南港”，结果一样，而“星星很亮，心里高兴”能听对。
     判断是“-ng”后面紧跟“n”连读时听起来像“-n”，读音本身没问题，字幕写的是“兴南港”，就留着了。
   - 旁白整体提前 0.7 秒（`NARR_OFF = -0.7`），第一句 0.3 秒开口。
2. **画面**（`shots.py`）：40 张新图 + 第 2 集的 3 张（`ep2_w1`、`ep2_w2`、`ep2_s10`）+ 战士设定图；8 段动画；52 个镜头。
   - 第一遍有 6 张重画：路灯和护栏太现代、黄色的现代吊车、钢桥画成了大桁架、照片里的人没有脸。
   - 一段动画第一次提交时接口报 502，没有创建任务（查了任务列表，没扣钱），重新提交。
3. **出图、做动画**：`python3 gen.py images`、`python3 gen.py clips`（flash 2560×1440；mini 720p，5～6 秒）。
4. **配乐和音效**：`python3 music.py` → `bgm.wav`。VSCO 2 CE 采样（Versilian Studios）；音效这集加了运输机、铁件撞击和修桥的敲打、电台、海浪、汽笛（`tools/story/sfx.py`）。
   - 第一帧一声定音鼓；炸药响了以后音乐停住，只剩风；“一共被炸了三次”三下鼓；最后“致敬”停在 D 大调。
5. **出片**：`python3 render.py`（`--frames 0,5,62` 只出截图）。竖屏直接在这里拼。
   - 字幕放在画面下面，竖屏一行最多 15 个字，太长的从中间附近的“的”后面断开。
   - 郭荣熙那句话用宋体大字打在画面上，最后“致敬 / 每一个去炸桥的人”，这两句不出底下的字幕。
