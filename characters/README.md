# 角色素材（Wojak 格式，No.51 起）

角色都用频道主给的图，不用自己生成的形象。

## 主人公 `hero/`
- `ref.png`：频道主给的原图（1024×1536，白底）。
  - 他戴黑色毛线猫耳帽，穿黑衬衫、黑阔腿裤。一只黑猫趴在他右肩（画面左边）。
  - **衣服不换**，一直穿这一身。
- `base.png`：原图只换了猫眼颜色，画面左边那只眼睛橙、右边那只青，跟以前的品牌黑猫小黑一样。
  - 用 `tools/wojak/cat_eyes.py` 做，表情都在这张上改。
- `expr/*.png`：8 个表情，透明底，原图的 2 倍大（2048×3072 抠图后裁成 1002×2992）。
  - 都是在 base.png 上改眉毛、眼睛、嘴做出来的，保证一直是同一个人。

  | 文件 | 表情 | 改了什么 |
  |---|---|---|
  | `calm` | 平静（原图） | 不改 |
  | `sad` | 难过 | 眉毛内侧往上挑，嘴角往下，额头上有两道纹 |
  | `cry` | 哭 | 难过 + 两道眼泪 + 嘴瘪着 |
  | `happy` | 开心 | 眉毛放松，嘴角往上 |
  | `shock` | 震惊 | 眼睛瞪圆、瞳孔变小，眉毛抬高，嘴张成 O |
  | `angry` | 生气 | 整张脸变红，眉毛压成 V，咬着牙 |
  | `meh` | 无语 | 眼皮耷拉一半，眉毛、嘴都是平的 |
  | `awkward` | 尴尬 | 脸红，太阳穴挂一滴汗，嘴角歪着笑 |
- `表情一览.png`：8 个表情排在一起。

**怎么做的**
1. 在底图上把眉毛、眼睛、嘴擦掉（用脸的底色 `#fcfcfc`），再画上新的。线条两头细、中间粗，跟原图的墨线一样。
2. 原图五官的坐标是逐像素量出来的，写在 `tools/wojak/expressions.html` 里，只对这张原图有效。
3. 用 `tools/wojak/cutout.py` 抠掉白底：从画面四边往里找连着的白色当背景，所以脸、脖子这些被线围住的白色不会被抠掉。

```
python3 -I tools/wojak/cat_eyes.py characters/hero/ref.png characters/hero/base.png
NODE_PATH=$(npm root -g) node tools/wojak/make_expressions.cjs characters/hero/base.png characters/hero/expr          # 全部表情
NODE_PATH=$(npm root -g) node tools/wojak/make_expressions.cjs characters/hero/base.png characters/hero/expr cry      # 只出一个
```

## 其他角色 `cast/`
从频道主给的两张设定图（`cast/sources/`）里一个个抠出来的半身像，透明底，底边是平的，放的时候贴着画框底边。

| 文件 | 设定（设定图上写的） |
|---|---|
| `女同事-行政` | 说话温柔，喜欢八卦，经常找你帮忙 |
| `女同事-技术` | 高冷，不爱说话，但其实很靠谱 |
| `女同事-运营` | 开朗活泼，喜欢自拍，经常带奶茶 |
| `领导-上司` | 有点油腻，爱吹牛，只会开会 |
| `同事-老哥` | 玩游戏很厉害，话多，但人不错 |
| `女同事-设计` | 有点文艺，喜欢拍照，审美很好 |
| `上级-主管` | 比较严厉，事多，但也会帮忙 |
| `同事-实习生` | 年轻，懂点技术，还挺努力 |
| `女同事-财务` | 认真负责，不太爱说话，但很细心 |
| `同事-技术大佬` | 很少说话，但技术很牛，话少的可怕 |
| `女同事-市场` | 甜美系，喜欢聊天，有点小作 |
| `大领导` | 更油腻，只会指挥，很少出现 |
| `卫衣帽子男`、`军人`、`灰发男`、`蓝卫衣男`、`眼镜男`、`背心男` | 第二张图，没写设定，可以当朋友、路人、室友 |

- `一览.png`：18 个人排在一起。
- **原图不大**：第一张图每人约 300 像素宽，第二张约 400 像素宽。放大到半个画面时会有点虚。频道主如果有更大的原图，换上重新抠就行。
- 设计、市场两个人的头发外面有一圈白边，是原画自带的，留着了。

**抠图**：用 `tools/wojak/cut_sheet.py`。
- 每个角色给出它所在的格子。
- 底边会砌一道 8 行宽的“墙”再切掉：格子底边常有一道浅色细线，不砌墙的话，背景会顺着它流进白色的手和衬衫。
- `--bottom-only` 只留碰到底边的部分，用来去掉设定图上写的字。
- 某处漏了，可以用 `wall:x0:y0:x1:y1` 手动补一道墙（`背心男` 的左臂就是这样补的）。

```
R1=0:432; R2=432:800; R3=800:1199
python3 -I tools/wojak/cut_sheet.py characters/cast/sources/办公室同事.png <输出目录> --bottom-only \
  行政:55:335:$R1 技术:335:645:$R1 运营:645:944:$R1 领导:944:1312:$R1 老哥:0:318:$R2 设计:318:620:$R2 \
  主管:620:944:$R2 实习生:944:1312:$R2 财务:0:280:$R3 技术大佬:280:602:$R3 市场:602:918:$R3 大领导:918:1312:$R3
python3 -I tools/wojak/cut_sheet.py characters/cast/sources/男生六人.png <输出目录> \
  卫衣帽子男:0:406:0:626 军人:406:853:0:626 灰发男:853:1254:0:626 蓝卫衣男:0:404:626:1254 眼镜男:404:802:626:1254 背心男:802:1254:626:1254 \
  wall:805:980:805:1214
```

其他角色要换表情时，照主人公的办法改五官，坐标要重新量。

**朝向**
- 两个人对话要面对面：主人公朝右，站在左边。对方站在右边，原图朝右的就左右翻过来。
- 用之前先看一眼这个角色原图里脸朝哪边，写进 `scenes.js` 的 `CAST[...].face`（1 = 朝右，-1 = 朝左）。
- 已经看过的：`同事-老哥`、`女同事-行政`、`领导-上司`、`女同事-运营` 都朝右。

**怎么用**
- 全身像的人比较小：头只有 40–60 像素宽。
  - 适合远景，比如人站在街上、操场上，从头到脚都在画面里；
  - 中景、近景要放大，会发虚。办公室那几个人用上面的半身像，清楚得多。
- **朝向**：设定图里的人大多是侧着身子的。用之前先看一眼脸朝哪边，规则跟半身像一样（对话时面对面，站在右边的朝右就翻过来）。
- **全身像都是频道主给的**，不用 AI 自己补下半身（试过一次，频道主说太丑）。

**怎么抠的**：`tools/wojak/cut_full.py`，每个人给一个框住全身的格子。
- 背景：格子四边的颜色，从四边往里找连着的。
- 脚下的浅灰影子、格子之间的竖分隔线都去掉了。
- 被人围住的背景（胳膊和身子之间、两腿之间）也挖掉了；苏瑶的白裙子跟背景太像，加了 `:noholes`，不挖洞。

## 放进视频的样子
`样子_办公室.png`：
- 竖屏 1080×1920，照片画框在中间（y 470–1430），上方是封面钩子。
- 人物露出半身站在照片前面。说出口的话用白色椭圆框，心里想的用淡蓝泡泡。
- 水印“@黑猫不说话”保留，没有进度条（`meta.json` 写 `"progress": false`）。

`tools/wojak/gen_images.py`（MiniMax 生图）也还留着，但频道主说角色不用自己生成的。以后要生成背景之类的东西时可以用。
