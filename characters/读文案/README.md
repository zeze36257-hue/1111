# 读文案短视频的角色

频道主 10 月 28 日定的（参考图是频道主发来的 `参考_两个人_1.png`、`参考_两个人_2.png`）。

| 谁 | 样子 |
|---|---|
| 他（主人公） | 黑色猫耳毛线帽（翻边有竖纹，右边一块小布标：黑猫，眼睛左橙右青）；白色圆脸、黑边；两颗黑豆眼；一边眉毛挑起来（“无语”）；嘴是一条短线 |
| 她 | 黑色猫耳毛线帽，右耳上一个粉色蝴蝶结；黑长直头发、刘海；白色圆脸、黑豆眼带一点高光；粉色腮红；微笑 |
| 别的人 | 白色圆脸、黑豆眼，深灰色短发，不戴帽子（跟他们俩区分开） |

- 露出来的皮肤（手、胳膊、脖子、腿）都是白的，外面一圈黑边，像参考图里那样。
- 不用白猫（第一版方案里的，频道主没要）。
- 头是 `tools/catify/catify.py` 里画的（him / her / friend），换到照片上的样子见 `refs/读文案/形象_第二版.jpg`。
