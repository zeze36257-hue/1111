# 设置教程：不用 Claude 账号，两个人用暗号一起写

做完以后：
- 你对象**不用注册任何东西**。打开一个网址，输入你们俩约好的暗号，就能一起看、一起写。
- 网页放在 GitHub 上，记录存在 Supabase（一个免费的数据库服务）里。
- 文字和照片在手机上就**用暗号加密**了。服务器上只有乱码，别人看不懂，Supabase 也看不懂。

这些步骤**只需要你做一次**，大概 10 分钟。注册的时候可以开着 VPN。

---

## 第 1 步：新建一个放网页的仓库（2 分钟）

1. 打开 https://github.com/new
2. **Repository name** 填 `love`
3. 选 **Public**（免费的网站只能放在公开仓库。仓库里只有网页代码，你们的记录不在这里。）
4. 勾上 **Add a README file**
5. 点 **Create repository**
6. 在新仓库页面点上面的 **Settings**，再点左边的 **Pages**
7. **Source** 选 **Deploy from a branch**，**Branch** 选 `main`、`/ (root)`，点 **Save**

## 第 2 步：注册 Supabase，建数据库（5 分钟）

1. 打开 https://supabase.com ，点 **Start your project**，选 **Continue with GitHub**，用你的 GitHub 账号登录
2. 点 **New project**：
   - **Name**：填 `love`
   - **Database Password**：点 **Generate a password**，把密码存在备忘录里（以后一般用不到，**不用发给我**）
   - **Region**：选 **Northeast Asia (Tokyo)** 或 **Southeast Asia (Singapore)**，离国内近，打开更快
   - 点 **Create new project**，等一两分钟
3. 左边点 **SQL Editor**，把 [`supabase.sql`](supabase.sql) 的**全部内容**复制、粘贴进去，点 **Run**。
   如果弹出提示问你确不确定，点确认。看到 `Success` 就好了。
4. 找到这两样东西（点项目页面上面的 **Connect** 按钮，或者 **Project Settings → API Keys / Data API**）：
   - **Project URL**：长得像 `https://abcdefgh.supabase.co`
   - **Publishable key**（以 `sb_publishable_` 开头），或者旧版的 **anon public** key（以 `eyJ` 开头）

> ⚠️ 只发这两样。**secret key、service_role key、数据库密码都不要发给任何人。**
> Publishable key 本来就是公开放在网页里用的，发给我没问题。

## 第 3 步：把这两样发给 Claude

告诉 Claude："仓库 love 建好了，URL 是……，key 是……"。我会把它们填进网页，然后发布到你的新仓库。

1～2 分钟以后，网址就是：**https://你的GitHub用户名.github.io/love/**

## 第 4 步：约暗号，发给 TA

1. 你先打开网址，输入暗号，点 **新建手账**
2. 把网址用微信发给 TA，**TA 不开 VPN 试着打开**，输入同一句暗号

关于暗号：
- 至少 8 个字，用一句只有你们俩知道的话，比如"第一次见面在三号线"
- 每个字、每个标点都要一模一样
- **暗号丢了就打不开了**（为了加密，谁都没办法帮你找回）。记在只有你们知道的地方

## 原来在 Claude 链接里写的内容怎么搬过来？

在原来的 Claude 链接里点最下面的 **导出备份**，然后在新网址里点 **从备份恢复**，选那个文件就行。

## 小提示

- 一周都没人打开的话，免费的 Supabase 项目会暂停。仓库里的"保持数据库醒着"任务每 3 天会自动访问它一次。
  万一还是被暂停了，登录 supabase.com，点项目里的 **Restore** 就能恢复，记录不会丢。
- 换手机、换浏览器，输入同一句暗号就能看到全部记录。
- 页面最下面的 **换暗号 / 退出**：会清掉这台手机上的副本，云端的记录不受影响。
