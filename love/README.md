# 我们的恋爱手账 💕

一个记录恋爱的小网页。只有一个文件：`index.html`，不用装任何软件。

## 能做什么

- **在一起第几天**：填上在一起的日子，自动算天数，以及「几年几个月几天」
- **时光**：写日记，可以加日期、标题、标签和一张照片，按月份排好
- **纪念日**：自动算 100 天、520 天、1000 天、周年；也能自己加生日等，显示倒计时
- **心愿清单**：写下想一起做的事，做完打勾，看进度条
- **备份**：页面底部「导出备份」会存一个 `.json` 文件，换手机或换浏览器时用「从备份恢复」导回来

## 怎么打开

**方法零（推荐，对象不用注册）**：照着 [设置教程.md](设置教程.md) 做一次，两个人打开同一个网址、输入同一句暗号就能一起写，国内不开 VPN 也能用。

**方法一**：用 Claude 发给你的链接，手机和电脑都能直接打开。分享给对象后，你们看到的是同一份记录。

**方法二（自己的电脑上）**：把 `index.html` 下载到电脑上，双击，用浏览器打开就行。
这种方式下记录只保存在这台电脑的这个浏览器里，记得常点「导出备份」。
