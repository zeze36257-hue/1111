## 一镜到底：主角是一个“圈”

| 段落 | 正片时间 | 画面与转场 |
| --- | --- | --- |
| 问题 | 0–19.2 | 封面“越追，越跑”。橙色那只连发三条消息，蓝色那只的未读数字一直涨。一个往前一步，一个往后退一步。两只猫心里分别想着“想静一静”和“他要走了…”。两只跑起来时，**地面卷成一个圈**。**镜头升上去从上往下看**，两只猫变成两颗光绕着圈追，圈中间出现题目 |
| 为什么在一起 | 19.2–41.6 | **圈缩成一格**，周围长出 354 格，每一格是一对恋人。两个都焦虑、两个都回避的组合：0 对。**镜头钻回那一格**：圈放大、侧过来、**摊平成地面**，两颗光变回两只猫。一个退后，一个缠上去，各盖一个“印证”章 |
| 一个圈 | 41.6–67.2 | **地面又卷成圈**。一个带着警报去追（发消息、追问、要一个答案），一个结着冰往后跑（不回、沉默、冷下来）。屏幕上出现“要求—退缩”。越转越快，两颗心里的光越来越少，圈越磨越深 |
| 分不开 | 67.2–83.2 | 蓝色那只想跑出圈，被线拉了回来。第 1 年、第 2 年、第 3 年一晃而过。打分 ★★☆☆☆，却意外地稳定，圈亮得发白 |
| 怎么办 | 83.2–108.8 | 两只猫停下，“看见”这个圈（圈变成金色）。说一句“我们又在转圈了”，两只一起**走出圈**、并排坐下，各说一句直接的话。**身后的圈碎成光**。最后是大字和评论区 |

两只猫在圈上跑的速度写在 `SPEEDS()` 里（每只猫一条速度轨道），INIT 时积分成跑过的角度。所以画面是时间的纯函数，追得最近的时候两只也至少隔着 0.32π，不会叠在一起。

## 音乐：原创配乐（`music.py`），E 小调绕圈，最后转 G 大调

75 BPM，1 小节 = 3.2 秒。

- 前四段都绕着同一组和弦 Em – C – G – D 转，**从来不回到主和弦**，就像两只猫一直在追。开头的小旋律最后也停回它开始的那个音。
- 圈越转越快时，钢琴变成同一个音的十六分音符，底下有心跳。
- “怎么办”这一段先走 C – D，绕不下去了。之后开头的旋律换成小提琴，在 G 大调上往上走，最后在“一个怕被丢下，一个怕被困住”那里走 D → G，这是全片唯一一次真正落到主和弦。
