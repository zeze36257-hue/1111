# No.51《今晚聚餐，你去不去？》对白本

Wojak 叙事短剧，演一件日常小事，不讲道理：下班前同事约聚餐，嘴上说“去啊”，心里只想回家。
- **时长**：正片 116.8 秒（38 句台词），加片尾约 2 分钟。
- **开头和结尾**：没有片头，第一帧就是封面；没有进度条；片尾和水印保留。
- **画面**：
  - 一场戏一张背景图，取景基本不动；
  - 人物是半身像，站在照片前面；
  - 两个人说话时面对面。
- **对话框**：说出口的话用白色椭圆，心里想的用淡蓝泡泡。主人公的表情随台词换。

## 对白

`（想）` 表示心里想的。

### ① 公司（下班前五分钟）
封面：**下班前五分钟，同事问我：今晚聚餐去不去？**

| 谁 | 台词 | 表情 / 画面 |
|---|---|---|
| 小黑（想） | 还有五分钟下班。今天终于能早点回家躺着了。 | 开心 |
| 老哥 | 哎，今晚部门聚餐，你去不去？ | 老哥从右边过来；小黑震惊 |
| 小黑（想） | 不想去。 | 无语 |
| 小黑（想） | 可大家都去，就我不去，会不会显得很不合群？ | 尴尬 |
| 老哥 | 就差你一个了！ | 震惊 |
| 小黑 | 去啊！当然去！ | 开心（装的） |
| 小黑（想） | 等等……我刚才说了什么？ | 哭 |
| 老哥 | 那七点，楼下火锅店见！ | 尴尬 |
| 小黑（想） | 离七点还有一个小时。我已经开始累了。 | 无语 |

## 声音

- **配乐**：只有“到家”那段有，一段很轻的钢琴（`music.py`，F 大调）。前面三段只有环境声。
- **环境声**：
  - 公司：空调、电脑的底噪和键盘声；
  - 火锅店：一桌人在聊、偶尔一阵笑、碗筷声；
  - 回家路上：夜里的街。
