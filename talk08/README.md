# 黑猫不说话 No.51《今晚聚餐，你去不去？》

第一期**纯叙事**的 Wojak 短剧：演一件日常小事，不讲道理。写法照着 `talk07/`，不同的地方如下。

## 故事和场景
四场戏，一场一张背景图，取景基本不动：

| 场景 | 背景 | 人物 |
|---|---|---|
| 公司 | `office.jpg`（和 talk07 同一个办公室） | 主人公在左；老哥从右边过来 |
| 火锅店 | `hotpot.jpg`（MiniMax 生成） | 主人公在左；运营、老哥在右（老哥在后面，小一点） |
| 回家路上 | `nightstreet.jpg`（MiniMax 生成，虚化过） | 主人公在左；老哥说完拜拜往右走掉 |
| 家 | `livingroom.jpg`（和 talk07 同一个家） | 主人公一个人（脸在 x≈400），往沙发上一倒 |

两个人说话时面对面：老哥、运营原图都朝右，站在右边时左右翻过来（`person()`）。

## 这一期的小把戏（都在 `scenes.js`）
- **一串“对”**（`hotpotLayer`）：
  - 主人公说完“哈哈，对。”后，冒出 7 个小对话框（不配音），头顶的计数“对 × N”一直加到 8；
  - 同时人头顶上方一句句冒出别人的聊天（`CHATTER`），轮流出现在 4 个位置，互不重叠。
- **聚光灯**（`spotlight`）：被问“周末干嘛”时全场暗下来，只有主人公在光里。他说完“睡觉”后，出现“……（唧——唧——）”。
- **合照**（`snapshot`）：先出现取景框的四个角，然后闪光灯。这张合照后面会出现在手机里。
- **电池**（`battery`）：回家路上红色 1%、一闪一闪；到家后慢慢充到 100%。
- **手机**（`phone`）：部门群里老哥发的合照，画面是火锅店加三个人的小半身像；红圈圈住主人公。
- **猫“喵～”**：`猫` 是一个说话的角色，对话框指着主人公肩上的猫（`HERO.cat`）。猫说话时，主人公不会变暗。

## 声音
- **配乐**（`music.py`）：只有“到家”那段有一段很轻的钢琴，前面是静音，响度 −20 LUFS，比以前轻。
- **环境声和小音效**：这一期在 `tools/cine/audio.py` 新加了 `room`、`chatter`、`night`、`cricket`、`clink`、`shutter`、`pop`、`lowbat`、`door`、`flop`。

## 出片
```
MUSIC_ASSETS=<乐器采样目录> NODE_PATH=$(npm root -g) tools/make_cine.sh talk08 今晚聚餐你去不去_No51.mp4
```
改台词：
1. 改 `layout.py` 的 SCRIPT；
2. `python3 ../tools/cine/tts.py .`；
3. `python3 layout.py`；
4. 看 `scenes.js` 里的 `HX`（每句的表情）是不是还对得上；
5. 出片。
