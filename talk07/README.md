# 黑猫不说话 · 心理学 No.50《高敏感人群：不是你太敏感，是你感受得更多》Wojak 版

这是第一期 **Wojak 格式**：把 talk06 的高敏感人群重做了一遍，只把画面里的黑猫换成频道主给的 Wojak 角色。台词、配音（`voice/` 直接从 talk06 拷来）、配乐（`music.py`）、时间轴都没变。

## 和 talk06 不一样的地方

**背景**：一场戏只用一张图，中途不换，取景基本不动（频道主要求）。
- 街上、公司、卧室、客厅（学姐整场对话）、公园（第二天到结尾）。
- talk06 里“怎么办”切到台灯照片、结尾换长椅照片，这一版都去掉了。

**人物**
- 人物是半身像，站在照片前面，用屏幕坐标画，不跟着照片推拉。
  - 主人公的帽子耳朵尖在 y≈760（`HERO.top`）；其他人贴着画框底边（y = 1430）。
- 两个人说话时面对面：
  - 主人公在左边（脸在 x≈320），朝右；
  - 对方在右边（x≈830）。原图朝右的（`CAST[...].face = 1`）会自动左右翻过来。
- 主人公的表情随台词换（`HX`，第 i 句开始时换，0.15 秒淡入）：难过、无语、尴尬、哭、震惊、开心……
- 说话的人会轻轻上下动，别人说话时听的人稍微暗一点。
- 角色分配：
  - 老哥（原来的阿橘）= `同事-老哥`；
  - 学姐 = `女同事-行政`；
  - 老板 = `领导-上司`。老板这一版露脸了：从右边进来说一句，说完就走。

**对话框**
- 统一放在画框上部（顶边在 y≈500），尾巴指向说话的人头顶。
- 说话的人不在画面里时，对话框标上名字，比如学姐在台灯那一段。

**讲知识的小图示**
- 画在压暗的画框中下部，跟对话框错开。“五个人里一个”“双胞胎”“不是病”这几张压得更暗（`dimFrame(a, .94)`），后面的人看不见，不显得乱。
- 小人用的是角色图：
  - “五个人里一个”：老哥、运营、主人公、实习生、行政，主人公亮起来；
  - 双胞胎：两个眼镜男；
  - 糟糕/好的环境：主人公难过/开心。

**画框上下的黑边**
- 上面：第一段是封面钩子“人一多就累，一句话能想一整天”，之后换成标题“高敏感人群 / 不是你太敏感，是你感受得更多”。
- 下面：最后的字卡。

**片头、片尾、进度条**：没有片头（`"intro": false`），没有进度条（`"progress": false`），片尾和水印保留。

**对白和引用**：都在 `文案.md` 里。
