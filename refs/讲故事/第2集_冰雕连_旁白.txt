# 第 2 集：冰雕连
# 旁白稿，给 tools/voice/narrate.py 用：一行一句；行尾 |秒数 是说完停多久；空行分段。核对情况见 第2集_冰雕连.md。
# 开头先有 10 秒左右只有画面和声音（风雪、结霜的眼睛睁开、雪地里趴着的人、远处的炮火和照明弹），旁白从第一句开始。

# 开头
{1950|一九五零} 年冬天，朝鲜，长津湖。|1.5
零下四十多度。|2
一个连的人，趴在雪地里，枪口对着山下的路。|2
到了第二天凌晨，阵地上，再也没有响起一声枪响。|2.5
不是他们撤了。|1.5
是他们一个都没有离开。|3.5

# 一、南方来的兵
{1950|一九五零} 年十一月，志愿军第九兵团紧急入朝。|1.2
他们要对付的，是美军的王牌部队，陆战第一师。|1.5
他们刚从华东过来，身上的冬装，是按江南的天气缝的。|1.5
东北军区拿出了库存的大衣，可数量有限，很多人没有分到。|1.5
就这样，他们走上了盖马高原的冰天雪地。|1.2
长津湖一带，夜里能冷到零下四十度。|2
冻伤的人，一天比一天多。|2.5

# 二、死鹰岭
十一月二十七日，志愿军在长津湖向美军发起了进攻。|1.5
第二十军五十九师一七七团二营六连，接到了一个任务：|1.0
埋伏在死鹰岭，堵住敌人突围的路。|2
埋伏，就不能生火，也不能乱动。|1.5
一百多个人，就这样趴在雪里，等。|2.5
天黑了，又亮了。|3

# 三、雪
风一阵一阵地刮，雪落在他们的背上，越积越厚。|2
敌人来了。|1.5
他们开了枪，一次又一次，打退了敌人的突围。|2
到了第二天凌晨，阵地上，再也没有响起一枪一炮。|3
战斗结束以后，战友们走上了死鹰岭。|1.5
他们看见，阵地上的人，还保持着战斗的样子。|1.5
有人趴着，手里还握着枪，枪口对着敌人来的方向。|2.5
全连一百二十五名官兵，牺牲在了阵地上。|3
他们是被冻死的。|3.5
很多人到最后，都还保持着射击的姿势。|3

# 四、纸条
在战士宋阿毛单薄的衣服里，战友们找到了一张纸条。|1.5
上面写着：|1.2
“我爱亲人和祖国，更爱我的荣誉。”|2
“冰雪啊，我绝不屈服于你，哪怕是冻死，我也要高傲地耸立在我的阵地上。”|3.5
后来，人们管他们叫“冰雕连”。|2
这张纸条，成了这个连队的传家宝。|3

# 五、这一仗
长津湖这一仗，志愿军把美军赶出了朝鲜东北部。|1.5
可志愿军也付出了巨大的牺牲。|3

# 结尾
七十多年过去了。|1.5
长津湖的雪，每年冬天还会落下来。|2
很多人是从电影《长津湖》里，第一次知道了他们。|1.5
可在那之前，他们已经在雪里，等了七十多年。|3
他们没有后退。|1.5
他们把自己，留在了阵地上。|2.5
一百二十五个人，一个都没有离开。|3.5
致敬，冰雕连。|3
