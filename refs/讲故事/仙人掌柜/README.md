# 仙人掌柜

新账号的 IP，11 月 3 日频道主选定。
- 是谁：沙漠里开小酒馆的仙人掌，给来往的客人讲故事。
- 名字：仙人掌 + 掌柜，双关。

## 样子（标准形象）
- 绿色的仙人掌身子，粗黑描边，平涂；两只椭圆黑眼睛带高光，粉色腮红，一条弯弯的笑嘴。
- 棕色牛仔帽，往右歪一点。红色帽带上别一朵粉色仙人掌花。
- 米白色围裙，带一个口袋。
- 左手举起来招手，右手拿着一个杯子（在擦杯子）。
