# 仙人掌柜

新账号的 IP，11 月 3 日频道主选定。
- 是谁：沙漠里开小酒馆的仙人掌，给来往的客人讲故事。
- 名字：仙人掌 + 掌柜，双关。

## 样子（标准形象）
- 绿色的仙人掌身子，粗黑描边，平涂；两只椭圆黑眼睛带高光，粉色腮红，一条弯弯的笑嘴。
- 棕色牛仔帽，往右歪一点。红色帽带上别一朵粉色仙人掌花。
- 米白色围裙，带一个口袋。
- 左手举起来招手，右手拿着一个杯子（在擦杯子）。

## 名字和简介（11 月 3 日他问的，等他定）
**账号名**（推荐第一个）：
1. **仙人掌柜 CACTALES**：CACTALES 是 cactus（仙人掌）加 tales（故事）拼起来的英文名，跟“迷因水母 MEMEPOP”一个路子。
2. 仙人掌柜：最短。
3. 掌柜讲故事：一看就知道讲故事，好搜。
4. 仙人掌柜讲故事：前两个都被占了时用。

名字能不能用，以抖音里能不能改成为准。

**设定**：
- 仙人掌柜在沙漠里开了间小酒馆，每晚给路过的客人讲一个故事。
- 管观众叫“客官”，粉丝也就叫“客官”。中式的“掌柜、客官”配西部的酒馆，有反差，好玩。

**旁白的固定开头和结尾**：
- 开头：“客官，坐。今晚讲个……”
- 结尾：“故事讲完了，酒也凉了。客官，明晚再来。”

**简介**（三种写法，推荐第一种）：
1. 像在跟人打招呼，跟迷因水母一个路子：
   ```
   嗨🌵 我是仙人掌柜
   在沙漠里开了间小酒馆
   每晚给路过的客官讲一个故事
   西部｜侠客｜传说｜奇闻
   ```
2. 直接说清楚做什么：
   ```
   一个讲，一个演
   每期一个真实又离奇的故事
   🌵 西部｜侠客｜传说
   ```
3. 开头就是钩子：
   ```
   客官，坐。
   今晚讲个什么呢——
   西部牛仔、江湖侠客、古老传说，一期一个。
   ```

**合集**：西部传奇、侠客列传、古老传说。
