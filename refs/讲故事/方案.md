# 动画讲故事：定下来的（11 月 3 日）

频道主看了我对参考视频（`参考1_沃铁熊.md`）的拆解后定的：
- **画面**：“哪个好用哪个办法”，交给我选。我选**火山方舟**：
  - Seedream 出图，Seedance 把图变成会动的镜头；
  - 其余镜头用我们自己的运镜、特效。
- **横屏 16:9**（1920×1080）。
- **一集要长一点**：一两分钟太短，讲不完一个故事，按参考视频的 4～5 分钟来。
- **题材**：
  - 他更喜欢历史，或者有趣的小故事；
  - 比如西方的侠客、西部牛仔这一类；
  - 传说、真事都行。
- **角色**：不用有固定的人设，也不用每集都长一样，跟着故事变。
  - 同一集里的主角要认得出来：衣服、发型前后一致。

## 一集怎么做
1. 选故事：我找资料、核对史实，写旁白稿。核对不到的说法用“据说”“有人认为”，或者不说。
2. 分镜：七八十个镜头，每个镜头写一句出图提示词。
   - 先给主角做一张设定图，后面的镜头都拿它当参考；
   - 风格：2D 动画电影感，暖色的西部色调。
3. 出图：用 Seedream。
4. 让关键的二三十个镜头动起来：用 Seedance。其余镜头用运镜、气泡、视差。
5. 旁白：用频道主找的那个人的声音，克隆后来讲。
   - 角色几乎不说话；必要时冒几个字的气泡。
6. 配乐跟着剧情走；音效、字幕、剪辑都由我做。

## 要频道主做的
- 开通火山方舟，开通 Seedream 和 Seedance，创建 API Key。
- 在环境设置里放开 `ark.cn-beijing.volces.com`，把 Key 存成 `ARK_API_KEY`，然后新开会话。
  - 生成的视频从哪个地址下载，第一次试的时候就知道了，到时候再请他加。
- 找人录一段声音，用来克隆旁白。

## 故事单（先列一些，他挑，或者我按顺序做）
1. **巴斯·里夫斯**：从奴隶到西部最让逃犯害怕的法警，最后亲手抓了自己的儿子。真事。第 1 集的稿子见 `第1集_巴斯里夫斯.md`。
2. **安妮·奥克利**：西部最有名的女神枪手。比枪赢了一个男人，那个男人后来成了她丈夫。真事。
3. **布奇·卡西迪和日舞小子**：抢火车的大盗，逃到南美，结局到现在都说不清。真事。
4. **威廉·退尔**：一箭射中儿子头顶的苹果。瑞士的传说。
5. **罗宾汉**：劫富济贫的绿林好汉。英国的传说。
6. **小马快递**：骑手接力送信，只干了一年多就被电报取代。真事。

## 新账号怎么弄（11 月 3 日他问的）
- **名字**（推荐第一个）：
  - **黑猫说书人**：“说书人”就是讲故事的人，正好是“一个讲，一个演”里讲的那个；
  - 黑猫夜话：有一点像讲鬼故事，可能会让人误会；
  - 黑猫讲故事：最直白。
  - 都带“黑猫”，猫眼标志接着用。名字能不能用，以抖音里能不能改成为准。
- **头像**：
  - 用频道原来的黑猫头像 `brand/头像_黑猫不说话.png`（820×820，黑猫，轮廓光左橙右青，异色瞳），讲什么题材都合适。
  - 想要西部味，可以做一版戴牛仔帽的。
- **简介**：
  ```
  我负责讲，他们负责演
  每期一个真实又离奇的故事
  西部｜侠客｜传说
  ```
- **主页背景图、合集**：
  - 背景图等有了 Seedream，画一张西部荒原、远处一只黑猫的剪影；
  - 合集叫“西部传奇”。
- **一上来就发视频可以吗**：可以。
  - 先把头像、名字、简介弄好；
  - 前几天刷刷同类的历史、故事视频，正常点赞、评论（这个说法不一定准，没有官方说明，但不费事）。
  - 头几条最要紧，系统靠它们认这个号是干什么的。所以头几条都发同一类故事，封面样式统一，节奏固定。
  - 一集四五分钟，做起来费工夫，先定每周两条，晚上发。
  - 不互关；每条声明 AI 生成。
