# 他和她的“表情包”：一次做完，以后每条不用再出图（11 月 2 日）

## 要解决的问题
新体系的《她说·她想》每条都要画他和她。以前的问题：
- 频道主每条都要自己出图，很累；
- GPT 每次画得都不太一样，有时脸不一样，有时没戴帽子。

## 办法：做一套固定的表情包，我来拼画面
- 频道主用 GPT 一次性画好：他 12 张、她 12 张。
  - 每张一个表情，胸口以上，纯绿背景；
  - 衣服固定；朝向固定：他朝右，她朝左，放在一起正好面对面。
- 我把绿色抠掉，放进场景里：
  - 按台词换表情，加字幕、配音；
  - 场景用 MiniMax 生成没有人的背景，跟 Wojak 短剧的做法一样（`talk07/` 的 `person()`）。
- 好处：
  - 他和她永远是同一张脸、同一顶帽子；
  - 频道主只做这一次。
- 纯色背景抠得很干净，跟以前从照片里抠人（`tools/catify/`，频道主说抠得不干净）不一样。
- 以后要拥抱、牵手这种两个人碰在一起的画面，偶尔单独出一张图就行。

## 试过：让 MiniMax 直接画（不行）
- 带参考图（从 14 里裁的他和她）各画了两张，对比见 `MiniMax试画_对比.jpg`。
- 能画出猫耳帽、黑头发、异色瞳，但是：
  - 脸跟参考卡不像；
  - 他的黑猫布标跑到了袖子上；
  - 她的蝴蝶结有时不在帽子上；
  - 猫耳朵里面是粉色的；
  - 还冒出了乱码字。
- 所以角色还是用 GPT 画，MiniMax 只用来画没有人的背景。

## 做法
- 他和她分两个对话画。
- 每个对话先上传 `../读文案/角色参考卡.jpg`，再发下面的“设定”；然后一条一条发表情。
- 每画三四张就再传一次参考卡。
- 每张检查四样：
  - 帽子；
  - 他的布标／她的蝴蝶结；
  - 他的眼睛（他自己的右眼橙、左眼青）；
  - 朝向。

### 设定（每个对话先发这段，同时上传参考卡）
```
接下来帮我给两个固定角色做一套“表情包”，以后做漫画短视频用。我上传的“角色参考卡”里是他和她。请先看清他们的样子，每一张都照着这张卡画，脸、发型、帽子、眼睛颜色都不能变。

【每一张的要求】
- 只画一个人，胸口以上的半身像，人物占画面的大部分；头顶的猫耳朵要完整画出来，不要被裁掉。
- 背景是纯绿色（#00FF00），一整块平的绿色：不要阴影、不要渐变、不要地面、不要任何别的东西。
- 画风跟参考卡一样的动漫插画：干净的黑色线条，平涂加一层柔和的阴影。
- 衣服固定，每一张都一样：他穿黑色连帽卫衣；她穿米白色的粗针织毛衣。
- 他：黑色猫耳毛线帽，帽檐上一块米白色小方布标（黑猫脸）；黑色碎发；他自己的右眼橙色、左眼青色。身体和脸都朝画面右边，四分之三侧面。
- 她：同样的黑色猫耳毛线帽，帽檐上一个粉色蝴蝶结；黑色长直发、齐刘海；深棕色眼睛。身体和脸都朝画面左边，四分之三侧面。
- 竖版 2:3；不要文字、水印、边框。

明白的话先回“明白”，我再一张一张告诉你画什么表情。
```

### 他（12 张，一次发一行）
```
画他：平静，嘴角放松，看着前面。
画他：微笑，眼睛弯一点。
画他：开心大笑，眼睛笑成弯弯的，露出牙齿。
画他：心虚，一只手挠后脑勺，额头一滴大汗，嘴角往下歪。
画他：震惊，眼睛瞪圆缩成小点，嘴张成小 O，头顶几根惊讶的线。
画他：无语，眼睛上半截被眼皮压平，嘴是一条直线。
画他：委屈，眉毛往下撇，嘴扁着，眼睛有点湿。
画他：生气，眉毛压成 V，咬着牙，额头一个小青筋。
画他：害羞，脸颊几道红色斜线，眼睛看向一边，一只手摸脖子。
画他：偷笑，一只手挡着嘴，眼睛眯起来。
画他：认真想事情，一只手托着下巴，眼睛往上看。
画他：低头看手机，手机拿在胸前，表情淡淡的。
```

### 她（12 张，一次发一行）
```
画她：平静，看着前面。
画她：微笑，脸颊淡淡的红晕。
画她：开心大笑，眼睛笑成弯弯的，露出牙齿。
画她：生气，鼓着腮帮子，两只手抱在胸前，头扭到一边。
画她：委屈想哭，眼眶红红的含着泪，嘴扁着。
画她：大哭，两道眼泪流下来，嘴张开。
画她：无语，眼睛半眯，嘴是一条直线，头上一个小汗滴。
画她：震惊，眼睛瞪圆，嘴张成小 O，一只手捂着嘴。
画她：害羞，两只手捂着脸，从指缝里偷看，脸很红。
画她：偷笑，一只手挡着嘴，眼睛眯起来。
画她：撒娇，嘟着嘴，眼睛水汪汪地往上看。
画她：低头看手机，手机拿在胸前，嘴角往下撇。
```

### 画得不对时补一句
| 问题 | 补这句 |
|---|---|
| 背景不是纯绿 | 背景要一整块纯绿色（#00FF00），什么都不要，重画。 |
| 没戴帽子、布标或蝴蝶结不对 | 照参考卡：他的帽檐上要有米白色黑猫布标，她的帽檐上要有粉色蝴蝶结。重画。 |
| 他的眼睛颜色反了 | 他自己的右眼橙色、左眼青色。他朝画面右边时，离我们近的那只是他的右眼（橙色），远的那只是青色。 |
| 朝向反了 | 他朝画面右边，她朝画面左边。 |
| 猫耳朵被切掉 | 人物缩小一点，头顶的猫耳朵要完整画出来。 |
| 脸不像 | 脸不对，照参考卡上他（她）的脸重画。 |
