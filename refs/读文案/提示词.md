# 读文案：给 AI 出图的提示词（第三版，10 月 31 日）

频道主拿去 GPT 里试。
- 第一版（扁平白色圆脸）他觉得死板。
- 第二版（正常脸型的日系插画）GPT 画成了精致的动漫脸，他也不要。
- 他要的是参考视频那种**简约的扁平漫画风**：
  - 粗黑描边、纯色平涂、最多一层硬边阴影；
  - 五官很少，脸型是正常人的，有点棱角；
  - 主角的皮肤是一种“不像真人”的纯色，一眼认得出；女生是浅肤色平涂。
- 标志留着：他的黑色猫耳毛线帽 + 异色瞳（画面左边橙、右边青）；她的猫耳帽 + 粉色蝴蝶结 + 黑长直。

用法：
- 一个对话里先发“角色设定”，后面每张图发“改这张照片”加照片；
- 表情从“表情清单”里挑一个填进去；
- 可以把参考视频的截图当画风参考一起传上去，但要说清楚“只学画风，不要画绿色皮肤、紫色头发的人”。

## 1. 角色设定（先发这一段）
```
接下来帮我改一批照片，做成同一个系列，风格请严格照下面来。

【画风（最重要）】
- 扁平的美式漫画 / 矢量插画风：粗而干净的黑色描边，纯色平涂，最多一层硬边阴影。不要渐变、不要高光反光、不要日系动漫的精致五官和大眼睛。
- 线条简单、带一点棱角，五官越少越好：鼻子一两笔，嘴一条线。
- 只把人的头、头发和露出来的皮肤（脸、脖子、手、胳膊、腿）画成这种扁平漫画；衣服、手里拿的东西、背景、光线全部保留真实照片原样（背景可以有一点虚化）。效果像在真实照片上直接画了一层漫画人物。

【他】
- 正常男生的脸型，下巴有点棱角，头比真人稍微大一点。
- 皮肤是纯白色平涂（像白纸一样），脖子、手也是同样的纯白，粗黑描边。
- 戴黑色针织毛线帽，帽顶有两只猫耳朵；帽子用纯黑平涂，加几条竖线表示针织纹；帽檐下露出一点黑色短发。
- 眼睛是两个简单的椭圆，没有瞳孔、没有高光：画面左边那只是橙色，右边那只是青色。这是他的标志，每张都要有。
- 平时面无表情、有点“无语”；需要时表情可以很夸张，但画法始终保持简单。

【她】
- 正常女生的脸型，尖下巴。
- 皮肤是浅肤色平涂，加一层颜色深一点的硬边阴影。
- 黑色长直发和刘海，用大块纯黑平涂，加几条线表示发丝；戴黑色针织猫耳毛线帽，右边耳朵上一个粉色蝴蝶结。
- 眼睛简单：杏仁形，深棕色虹膜，小小的黑瞳孔，眼神淡淡的；鼻子一笔，嘴一条线。
- 平时表情淡淡的、有点冷；需要时也可以很夸张。

【别的人】同样的扁平画法，皮肤用浅灰色平涂，头发深灰，不戴帽子，表情简单。

【每张图】一眼认得出是同一个他、同一个她；不要文字、水印、边框；竖版 2:3。
```

## 2. 改这张照片（每张图发一次，附上照片）
```
用上面的设定改这张照片：[左边的人是他，右边的人是她 / 只有他 / 只有她]。
- 把人物的头、头发和露出来的皮肤重新画成扁平漫画风的他（她）。姿势、手势、头的朝向跟原照片一样，头可以比原来稍微大一点。
- 手也画成同样的扁平风：粗黑描边、纯色平涂，手指的形状和动作跟照片一样。
- 他的表情：[从表情清单里挑，比如：无语——椭圆眼睛上半截被眼皮压平，嘴一条直线]。
- 她的表情：[……]。
- 衣服、拿着的东西、背景、光线、颜色、构图全部保持原照片不动。
- 不要画成精致的日系动漫，就是简单的扁平漫画。
```

## 3. 没有照片时：直接生成一张
```
用上面的设定生成一张竖版 2:3 的图：[写场景，比如：深夜的出租屋，暖黄色台灯，他坐在床边看手机]。
他的表情：[……]。
背景、衣服、房间、灯光都是真实照片的质感（背景可以有一点虚化）；只有人物的头、头发和露出来的皮肤是扁平漫画风，粗黑描边、纯色平涂。
```

## 4. 表情清单（简单的画法也能做出来的）
- **无语**：椭圆眼睛上半截被眼皮压平，嘴一条直线
- **震惊**：眼睛缩成两个小圆点，嘴张成一个小 O，头旁边一滴汗
- **坏笑**：一边嘴角往上挑，眼睛眯成一条线
- **难过**：眼睛下面挂一滴泪，嘴角往下撇
- **崩溃大哭**：两道泪像水管一样喷出来，嘴张成大大的方形
- **生气**：眉毛压成 V 字，咬着牙（嘴画成一排锯齿）
- **尴尬**：头旁边一滴大汗，嘴是歪歪的波浪线
- **害羞**（她）：脸颊上几道斜线，眼睛看向一边
- **开心**：眼睛弯成两个倒 U，嘴咧开
- **发呆**：眼睛空空的，嘴微微张开
- **心累**：眼睛半闭，头顶一团乱线

## 小提示
- 同一批图放在同一个对话里改，人物更容易保持一致。
- 画得太精致了：“简单一点，只要粗黑描边和纯色平涂，不要阴影渐变、不要高光”。
- 背景或衣服被改了：“背景和衣服恢复成原照片，只改人物的头、头发和皮肤”。
- 想换他的皮肤颜色（比如浅灰、雾蓝），把设定里的“纯白色”改掉就行。
