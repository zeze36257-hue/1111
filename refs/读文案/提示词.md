# 读文案：给 AI 出图的提示词（第五版，11 月 2 日）

频道主拿去 GPT 里用。

## 以前几版
- 第一版：扁平白色圆脸。他觉得死板。
- 第二版：正常脸型的日系插画。GPT 画成了精致的动漫脸，他不要。
- 第三版：照参考视频的简约扁平漫画风。
- 第四版：
  - 加了“表情让 AI 自己看照片设计”；
  - 加了“手绘感”。
  - 他用这版做了两批图（`../../characters/读文案/图/`），后来以这批图的样子为准。

## 第五版为什么改
频道主 11 月 2 日说，第四版做出来的图有两个问题：
- 脸每张都不一样；
- 有的有帽子、有的没有：05、07、12 都没戴。

原因：
- **只靠文字，GPT 每张都会重新想一张脸。** 要让它每次都看着同一张图画。所以做了 `角色参考卡.jpg`：
  - 从他认可的第二批图里裁的：他 14、11、15，她 14、10、13；
  - 标好了每个人的标志。
- **画风前后矛盾。** 第四版写的是扁平、纯白皮肤，可他实际做出来、也认可的图是动漫插画、正常肤色。GPT 在两种画风之间摇摆。第五版直接写“跟参考卡一样”。
- **没写清谁是他，路人又“不戴帽子”。** 12 里的年轻人就被当成了路人，帽子也就没了。所以每张都要写清谁是他、谁是她。
- **帽子没写成每张必须有。** 背影、穿正装、远景时容易被省掉。第五版把它写成必须做到的三条之一。

## 用法
1. 每一批图开一个**新对话**。
2. 第一条消息：上传 `角色参考卡.jpg`，发「1. 角色设定」。
3. 之后每一张：上传照片，**再传一次参考卡**，发「2. 改这张照片」，填好谁是谁。
4. 一个对话改到 8 张左右就新开一个，从第 1 步重来。对话太长，GPT 会慢慢忘掉前面的设定。
5. 每张出来先对一下「3. 检查」，不对就补那一句，让它重画这一张。

## 1. 角色设定（先发这段，同时上传参考卡）
```
接下来帮我改一批照片，做成同一个系列。我上传的“角色参考卡”里有两个固定角色：他和她。请先看清他们的样子，后面每一张都照着这张卡画。

【最重要的三条，每一张都必须做到】
1. 每一张都是同一个他、同一个她：脸型、五官、发型、发色、眼睛颜色都跟参考卡一模一样。不要重新设计，不要每张换一张脸。
2. 他和她每一张都戴着黑色猫耳毛线帽，没有例外：背影、侧脸、远景、室内、穿婚纱或西装、运动、躺着都要戴。照片里原来的帽子、头盔、兜帽、发箍，一律换成这顶猫耳毛线帽。
3. 他的眼睛是异色瞳：他自己的右眼橙色、左眼青色（正对镜头时，画面左边橙、右边青）。侧脸只露出一只眼睛时，也按这个规则涂色。

【他】
- 黑色针织毛线帽，竖条针织纹，帽檐往上翻一圈，帽顶两只尖尖的猫耳朵。帽檐正面偏一侧缝一块米白色的小方布标，上面是一只黑猫的脸。
- 黑色碎发，刘海盖到眉毛，几缕垂在眼睛之间；帽檐下面两边和后面露出一点头发。
- 脸瘦、下巴尖，五官清秀；平时表情淡淡的，笑起来露一点牙。正常的浅肤色。

【她】
- 同样的黑色猫耳毛线帽，帽檐正面偏一侧有一个粉色蝴蝶结（她的帽子没有布标）。
- 黑色长直发，长到腰，齐刘海，脸两边垂着几缕头发。
- 深棕色的大眼睛，睫毛明显，脸颊淡淡的红晕；小脸、尖下巴。正常的浅肤色。

【别的人】照片里除了他和她，其他人都是路人：画成同样的画风，但不戴猫耳帽、不是异色瞳，脸要跟他们俩明显不一样。

【画风】跟参考卡一样的动漫插画：干净的黑色线条，平涂上色加一层柔和的阴影。只把人物画成插画；背景、光线、构图保留原照片，像动漫人物站在真实的照片里。

【表情】每张你根据照片里的动作、场景和气氛来设计（有文案就配合文案），可以夸张一点，用汗滴、红晕、泪滴、小符号这些漫画画法。表情可以变，脸不能变。

【每张图】竖版 2:3；不要文字、水印、边框。

明白了的话，先用一句话说说他和她各自的标志是什么。
```

## 2. 改这张照片（每张都发；照片和参考卡一起上传）
```
照着参考卡改这张照片。
- 谁是谁：照片里【左边穿牛仔外套的男生】是他，【右边穿风衣的女生】是她，其他人都是路人。（只有一个人就写：照片里只有他／只有她）
- 他和她都要戴猫耳毛线帽：他的帽子上有黑猫布标，她的帽子上有粉色蝴蝶结；他的眼睛右眼橙、左眼青。
- 脸和发型跟参考卡一模一样。
- 姿势、手势、头的朝向、衣服的款式、背景、光线都跟原照片一样。
- 这张配的文案：【……】（没有就删掉这一行）
```
【】里的换成这张照片的实际情况。照片里的人原来戴着别的帽子、兜帽时，加一句：“把他原来的帽子换成猫耳毛线帽”。

## 3. 检查：出来以后对一下，不对就补一句，让它重画这一张
| 检查 | 不对时补这句 |
|---|---|
| 他和她都戴着猫耳帽吗？ | 他和她都要戴黑色猫耳毛线帽，照参考卡，重画这一张。 |
| 他的帽子上有黑猫布标、她的有粉色蝴蝶结吗？ | 他的帽檐上要有米白色的黑猫小布标，她的帽檐上要有粉色蝴蝶结。 |
| 他的眼睛是右眼橙、左眼青吗？ | 他的眼睛：他自己的右眼橙色、左眼青色，正面看是画面左边橙、右边青。 |
| 脸跟参考卡像吗？ | 脸不对，照参考卡上他（她）的脸重画，脸型、五官、刘海都要一样。 |
| 路人被画成了他或她？ | 【……】是路人，不戴猫耳帽，脸跟他们俩不一样。 |
| 背景、衣服被改了？ | 背景和衣服恢复成原照片，只改人物。 |

## 4. 没有照片时，直接生成一张
```
照着参考卡生成一张竖版 2:3 的图：【写场景，比如：深夜的出租屋，暖黄色的台灯，他坐在床边看手机】。
他（和她）戴着猫耳毛线帽，脸跟参考卡一模一样；他的眼睛右眼橙、左眼青。
背景是真实照片的质感，人物是参考卡那样的插画。表情你根据场景（和文案）来设计。
这张配的文案：【……】（没有就删掉这一行）
```

## 小提示
- 参考卡每次都要跟照片一起传，只在第一条消息里传一次不够。
- 做出特别满意的图，可以发给我，我把它加进参考卡，参考卡会越来越准。
