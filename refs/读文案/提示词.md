# 读文案：给 AI 出图的提示词（第四版，10 月 31 日）

频道主拿去 GPT 里试。
- 第一版（扁平白色圆脸）：他觉得死板。
- 第二版（正常脸型的日系插画）：GPT 画成了精致的动漫脸，他不要。
- 第三版：照参考视频的简约扁平漫画风（粗黑描边、纯色平涂、五官少）。
- 第四版加了两条：
  - **表情让 AI 自己看照片来设计**（姿势、场景、气氛，有文案就配合文案），不用每张手挑；
  - **所有人物都要有手绘的感觉**：像画师在照片上一笔一笔描出来的，线条有粗细变化，不要电脑矢量那种规整。
- 标志留着：
  - 他：纯白皮肤、黑色猫耳毛线帽、异色瞳（画面左边橙、右边青）；
  - 她：浅肤色、黑长直、猫耳帽 + 粉色蝴蝶结。

用法：
- 一个对话里先发“角色设定”，后面每张图只发“改这张照片”加照片；
- 有这张图要配的文案就填进去，没有就删掉那一行。
- 可以把参考视频的截图当画风参考一起传上去，但要说清楚“只学画风，不要画绿色皮肤、紫色头发的人”。

## 1. 角色设定（先发这一段）
```
接下来帮我改一批照片，做成同一个系列，风格请严格照下面来。

【画风（最重要）】
- 手绘感的扁平漫画：像画师拿数位板在照片上一笔一笔描出来的。黑色线条有自然的粗细变化（起笔收笔细、中间粗），可以有一点点手绘的不完美；颜色是纯色平涂，可以带一点手涂的笔触，最多一层硬边阴影。
- 不要电脑矢量那种完全规整的线条，不要渐变、不要高光反光，也不要日系动漫的精致五官和大眼睛。
- 五官越少越好：鼻子一两笔，嘴一条线；脸型是正常人的，带一点棱角。
- 只把人的头、头发和露出来的皮肤（脸、脖子、手、胳膊、腿）画成手绘漫画；衣服、手里拿的东西、背景、光线全部保留真实照片原样（背景可以有一点虚化）。效果像有人在真实照片上直接画了漫画人物。

【他】
- 正常男生的脸型，下巴有点棱角，头比真人稍微大一点。
- 皮肤是纯白色平涂（像白纸一样），脖子、手也是同样的纯白，黑色描边。
- 戴黑色针织毛线帽，帽顶有两只猫耳朵；帽子用黑色平涂，加几笔竖线表示针织纹；帽檐下露出一点黑色短发。
- 眼睛是两个简单的椭圆，没有瞳孔、没有高光：画面左边那只是橙色，右边那只是青色。这是他的标志，每张都要有。

【她】
- 正常女生的脸型，尖下巴。
- 皮肤是浅肤色平涂，加一层颜色深一点的硬边阴影。
- 黑色长直发和刘海，用大块黑色平涂，加几笔线表示发丝；戴黑色针织猫耳毛线帽，右边耳朵上一个粉色蝴蝶结。
- 眼睛简单：杏仁形，深棕色虹膜，小小的黑瞳孔；鼻子一笔，嘴一条线。

【别的人】同样的手绘画法，皮肤用浅灰色平涂，头发深灰，不戴帽子。

【表情：由你来设计】
- 每张图的表情你自己定：先看照片里的人在做什么、什么姿势、什么场景和气氛（如果我给了这张图配的文案，也要配合文案），然后设计一个最贴切、最有戏的表情。
- 表情可以夸张，像漫画一样；画法保持简单：靠眼睛的形状、眉毛、嘴，再加漫画符号（汗滴、泪滴、脸红的斜线、青筋、头顶的乱线、问号）。
- 两个人在一起时，两个人的表情要有互动（比如一个害羞，一个偷笑）。
- 不要每张都一样。可以参考这些画法：无语（眼睛上半截被眼皮压平，嘴一条直线）、震惊（眼睛缩成小圆点，嘴张成小 O）、坏笑（一边嘴角挑起）、难过（眼下一滴泪，嘴角往下撇）、崩溃大哭（两道泪喷出来）、生气（眉毛压成 V，咬牙）、尴尬（大汗滴，嘴是歪的波浪线）、害羞（脸颊几道斜线）、开心（眼睛弯成倒 U）、发呆（眼睛空空，嘴微张）。

【每张图】一眼认得出是同一个他、同一个她；不要文字、水印、边框；竖版 2:3。
```

## 2. 改这张照片（每张图发一次，附上照片）
```
用上面的设定改这张照片：[左边的人是他，右边的人是她 / 只有他 / 只有她]。
这张图配的文案是：[……]（没有就删掉这一行）
- 把人物的头、头发和露出来的皮肤重新画成手绘漫画风的他（她）。姿势、手势、头的朝向跟原照片一样，头可以比原来稍微大一点。
- 手也画成同样的手绘风，手指的形状和动作跟照片一样。
- 表情你根据照片（和文案）来设计，要贴切、有戏。
- 衣服、拿着的东西、背景、光线、颜色、构图全部保持原照片不动。
```

## 3. 没有照片时：直接生成一张
```
用上面的设定生成一张竖版 2:3 的图：[写场景，比如：深夜的出租屋，暖黄色台灯，他坐在床边看手机]。
这张图配的文案是：[……]（没有就删掉这一行）
背景、衣服、房间、灯光都是真实照片的质感（背景可以有一点虚化）；只有人物的头、头发和露出来的皮肤是手绘漫画风。表情你根据场景（和文案）来设计。
```

## 小提示
- 同一批图放在同一个对话里改，人物更容易保持一致。
- 画得太规整、像电脑画的：“线条要更有手绘感，有粗细变化，像画师一笔一笔描的”。
- 画得太精致：“简单一点，只要黑色描边和纯色平涂，不要渐变、不要高光”。
- 表情不够：“表情再夸张一点，像漫画里那样”。
- 背景或衣服被改了：“背景和衣服恢复成原照片，只改人物的头、头发和皮肤”。
- 想换他的皮肤颜色（比如浅灰、雾蓝），把设定里的“纯白色”改掉就行。
