# 读文案：给 AI 出图的提示词（第二版，10 月 31 日）

频道主拿去 GPT 里试。第一版（扁平白色圆脸）他觉得死板，改成：**正常人类的脸型，插画风，表情丰富、可以很夸张**。
标志留着：他的黑色猫耳毛线帽 + 异色瞳（画面左边橙、右边青，跟频道的黑猫一样）；她的猫耳帽 + 粉色蝴蝶结 + 黑长直。

用法：
- 一个对话里先发“角色设定”，后面每张图发“改这张照片”加照片；
- 表情从“表情清单”里挑一个填进去。

## 1. 角色设定（先发这一段）
```
接下来我要你帮我改一批照片，做成同一个系列。请先记住下面的设定，每张图都严格照着来。

【画风】
人物画成干净的日系插画风：清晰的黑色线条，平涂上色，加一层简单的阴影。脸型和五官比例是正常人类的，不要Q版，不要圆球脸。
照片里除了人以外的东西（衣服、背景、光线）都保持真实照片的样子。

【他】（主角，20多岁的男生）
- 黑色针织毛线帽，帽顶有两只小小的猫耳朵，翻边有竖条纹；帽子侧面有一块米白色小布标，上面是一个小黑猫头。
- 黑色短发，从帽檐下露出一点碎刘海。
- 眼睛是异色瞳：画面左边那只是橙色，右边那只是青色。这是他最重要的标志，每张都要有。
- 皮肤白皙，平涂。
- 表情很丰富，可以很夸张，像漫画一样：会瞪眼、会哭成宽面条泪、会脸红冒汗、会翻白眼、会憋笑；可以加漫画符号（汗滴、红晕、青筋、眼泪、闪光、黑线）。

【她】（女主角）
- 同样的画风，正常人类的脸。
- 黑色长直发，空气刘海。
- 黑色针织猫耳毛线帽，右边耳朵上一个粉色蝴蝶结。
- 深棕色的大眼睛带高光，脸颊淡淡的粉色腮红。
- 表情同样丰富夸张：害羞、鼓着腮帮子生气、笑出眼泪、委屈、翻白眼。

【别的人】同样画风的普通人，不戴帽子，头发是灰色或深棕色。表情可以夸张，但颜色低调，不抢他们俩的戏。

【每张图都要做到】
- 一眼认得出是同一个他、同一个她：帽子、发型、眼睛颜色都不能变。
- 不要文字、水印、边框；竖版 2:3。
```

## 2. 改这张照片（每张图发一次，附上照片）
```
用上面的设定改这张照片：[左边的人是他，右边的人是她 / 只有他 / 只有她]。
- 把人物的头和露出来的皮肤（脸、脖子、手、胳膊、腿）重新画成插画风的他（她）。姿势、手势、头的朝向和大小跟原照片一样。
- 他的表情：[从表情清单里挑，比如：震惊——眼睛瞪圆、瞳孔缩小，嘴张成O形，额头一滴冷汗]。
- 她的表情：[……]。
- 衣服、背景、光线、颜色、构图全部保持原照片不动，只有人物的头和皮肤变成画的。
- 画的部分要跟照片融在一起：光线方向一致，边缘干净，不要像剪下来贴上去的。
```

## 3. 没有照片时：直接生成一张
```
用上面的设定生成一张竖版 2:3 的图：[写场景，比如：深夜的出租屋，暖黄色台灯，他坐在床边看手机]。
他的表情：[……]。
人物的头和皮肤是插画风；衣服、房间、灯光、景深都是真实照片的质感，像一张真实照片里的人被画成了动漫人物。
```

## 4. 表情清单（挑一个填进去）
- **震惊**：眼睛瞪圆、瞳孔缩小，嘴张成 O 形，额头一滴冷汗
- **崩溃大哭**：宽面条泪，嘴张大往下撇，鼻涕泡
- **委屈**：嘴扁成波浪线，眼眶含泪，眉毛八字
- **尴尬**：脸通红，嘴角僵硬地笑，头旁边几滴汗
- **无语**：半眯着眼翻白眼，嘴是一条直线，额头三条黑线
- **偷笑**：眼睛眯成弯月，捂着嘴，脸颊发红
- **生气**：眉毛倒竖，咬着牙，额头一个青筋符号
- **发呆**：眼神放空，嘴微张，头顶一个小问号
- **感动**：眼里闪着泪光，抿着嘴笑，脸颊微红
- **心动**：眼睛里冒星星，脸红，嘴角上扬
- **累瘫**：黑眼圈，眼皮耷拉，头顶飘出一个小小的灵魂

## 小提示
- 同一批图放在同一个对话里改，人物更容易保持一致。
- 背景或衣服被改了：“背景和衣服恢复成原照片，只改人物”。
- 人物走样了：“他的眼睛必须是画面左边橙、右边青，帽子是黑色猫耳毛线帽”。
- 想更夸张：“表情再夸张一倍，像漫画里那样”。
