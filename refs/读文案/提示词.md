# 读文案：给 AI 出图的提示词

频道主 10 月 31 日要的，他拿去 GPT 里试。用法：
- 一个对话里先发“角色设定”，后面每张图只发“改这张照片”加照片；
- 手上有 `characters/读文案/参考_两个人_1.png` 的话，第一次一起传上去，说“角色照这张图画”。

## 1. 角色设定（先发这一段）
```
接下来我要你帮我改一批照片，角色设定如下，每张图都要严格保持一致：

【他】
- 头：一个完全扁平的白色圆脸，像贴纸一样平涂、没有阴影，外面一圈粗黑描边。
- 脸上只有：两颗小小的黑色圆点眼睛；两条短短的黑色眉毛（右边那条微微挑起，有点“无语”）；一条短短的直线嘴。没有鼻子、没有耳朵、看不到头发。
- 戴一顶黑色针织毛线帽，帽顶有两只小小的猫耳朵，翻边有竖条纹。帽子侧面有一块米白色小布标，上面是一个黑猫头，眼睛左橙右青。
- 露出来的皮肤（脖子、手、胳膊、腿）全部是同样的纯白色，平涂，粗黑描边，像漫画。

【她】
- 同样的扁平白色圆脸、粗黑描边；两颗稍大的黑色圆点眼睛，带一点白色高光；淡粉色腮红；小小的微笑。
- 黑色长直发，有刘海。
- 黑色针织猫耳毛线帽，右边耳朵上一个粉色蝴蝶结。
- 露出来的皮肤同样是纯白平涂、粗黑描边。

【别的人】扁平白色圆脸、黑豆眼、深灰色短发，不戴帽子。
```

## 2. 改这张照片（每张图发一次，附上照片）
```
把这张照片里的人改成【他】（如果有两个人：左边是他，右边是她）。
只改两样：头，和露出来的皮肤。
- 头换成角色设定里的样子，大小跟原来的头差不多，朝向跟原来的脸一样。
- 露出来的皮肤涂成纯白平涂加粗黑描边，手指、手势、姿势保持原样。
其余全部保持照片原样、不要动：衣服、头发以外的配饰、背景、光线、颜色、构图、画幅。
角色要像画进照片里的：边缘干净、线条粗细统一，跟照片的光线协调（有一点点环境光和投影），不要像剪下来贴上去的。
不要加文字、水印、边框。竖版 2:3。
```

## 3. 没有照片时：直接生成一张
```
一张写实的胶片风照片，竖版 2:3：[写场景，比如：夜里的出租屋，暖黄色台灯，他坐在床边低头看手机]。
画面里的人是角色设定里的【他】（和【她】）。
除了人物的头和露出来的皮肤是扁平漫画风（白色圆脸、粗黑描边），其余一切都是真实照片的质感：衣服的布料褶皱、房间、灯光、景深都要像真的照片。
不要文字、水印、边框。
```

## 4. 另一个方案（黑猫头），想对比时用
```
把这张照片里那个人的头换成一个扁平的黑猫头：圆脸、两只尖耳朵、纯黑平涂，外面一圈很细的米白描边；
眼睛左边橙色、右边青色，竖着的猫瞳孔；没有嘴。
露出来的皮肤（手、胳膊、脖子）涂成黑色平涂，外面一圈很细的米白描边。
其余全部保持照片原样（衣服、背景、光线、构图、画幅都不动），边缘干净，不要像剪下来贴上去的。不要文字、水印、边框。
```

## 小提示
- 如果它把脸画回真人脸，补一句：“脸必须是一个扁平的白色圆形，只有两颗黑色圆点眼睛、眉毛和一条线的嘴，不要画成真人的五官。”
- 改坏了不用重来，接着说哪里不对，比如“背景被改了，恢复成原照片”“手指画歪了”。
- 同一批图放在同一个对话里改，角色比较容易保持一致。
