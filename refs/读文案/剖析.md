# 读文案的短视频：剖析和我们的形象方案

频道主 10 月 28 日发来 4 条参考视频（抖音号 DADA_NO_SLEEP 的），说想做这种：
- 很短，读一段让人共情的文案；
- **以后文案频道主写**，我做画面切换、配音、字幕；
- 现在最难的是**形象**：要让人记住，又要合频道的人设。频道主想保留参考视频的做法：真实照片（情侣照、个人照），把露出来的身体部位换成自己的特色。

参考视频本身不放进仓库。**这个格式还没定**，下面是剖析和给频道主看的样子。

## 参考视频是怎么做的

| | 量出来的 |
|---|---|
| 时长 | 19–30 秒（四条：30.3、27.9、18.8、19.3 秒） |
| 画面 | 竖屏 720×1558；中间一张竖的照片（约 2:3，720×1050），上下是黑边 |
| 黑边上的字 | 老式摄像机的取景框：左上 “CAM”（绿色像素字），右上 “SP ▶” 和倒数的时间码，左下 “FEB.02:1987”，右下 “PM 08:26”。每条都一样，一眼认得出是这个系列 |
| 换图 | 一句话一张图，平均 1.8–2.1 秒一张（最短约 1 秒，最后一张停 4–5 秒） |
| 字幕 | 白色特粗黑体，粗黑边，居中，放在照片中间偏下；跟着配音一截一截冒出来 |
| 配音 | 男声，基频约 120 Hz（跟我们主角的“温润男声”差不多低），读得平稳，每秒约 5 个字 |
| 配乐 | 一直有一层轻的音乐垫在下面 |
| 片尾 | 没有自己的片尾（下载下来最后那几秒“来抖音 发现更多创作者”是抖音加的） |

**文案**（四条的原文大意）：
1. 年轻的我们执着于那些得不到的喜欢……直到 ta 在你心里留下一块伤疤，你才会意识到，其实感情不需要那么辛苦，让人感觉到快乐才是爱。
2. 为什么你不允许自己犯错呢？……世界上没有什么是完美的，当然你也一样。
3. 亲密关系最忌讳的，就是自己憋着不说，却希望对方读懂自己的内心……有情绪并不可怕，讲出真话才是解药。
4. 或许有一天你会明白，有些东西值得失去……能治愈你的从来都不是时间，而是对过去的释怀和淡然。

都是第二人称（“你”），一条只讲一个道理，每句都短。跟我们 Wojak 短剧“不说教”的规矩不一样：这种格式本身就是一段温柔的劝慰，频道主自己写。

## 形象：真实照片 + 自己的“标志色”

- 照片是真实的：情侣照、个人照，也有电影截图（**我们不用电影截图**，CLAUDE.md 里定过）。
- 他自己：
  - 头换成一个画的头：荧光绿的脸、紫红色的刺猬头、两只白色的空眼睛；
  - **露出来的手、胳膊、腿全涂成同一种荧光绿**，加黑色描边；
  - 衣服和背景是照片原样。
- 女朋友：红头发的动漫女生（脸、头发、皮肤画成平涂）。朋友：蓝脸黄头发。
- 为什么记得住：
  - 荧光绿加紫红，在信息流里很扎眼；
  - 头很简单，什么姿势都好画；
  - 只要露出一只手，就知道是他。

## 我们的形象方案（第一版，样子见 `形象方案.jpg`）

照片是 MiniMax 生成的写实照片，形象是 `tools/catify/catify.py` 自动换上去的。字幕、文案是示例。

### A：黑猫头（推荐）
- 头换成一个**黑猫头**：
  - 两只尖耳朵；
  - 眼睛左橙右青，就是品牌色，跟片尾那只黑猫一样；
  - 竖着的猫瞳孔；**没有嘴**，就是“不说话”。
- 露出来的手、胳膊、脖子涂成黑色（像黑猫的毛），留一点明暗，看得出手指；外面一圈很细的米白边。
- 另一半是**白猫**：蓝眼睛、粉鼻子、ω 嘴，长头发和皮肤保留照片原样。
- 好处：
  - 名字就是形象：一只不说话的黑猫；
  - 剪影（猫耳朵 + 黑脸）缩成很小的封面也认得出；
  - 画面里最亮的颜色就是那两只眼睛，跟参考视频的荧光绿一个道理，但是我们自己的；
  - 头很简单，能自动换，每天出片不靠手画。

### B：猫耳毛线帽
- 接现在 Wojak 主人公的帽子：黑色毛线猫耳帽，下面一张很简单的白脸，皮肤涂白。
- 能跟以前的视频连上，但白手像戴了白手套，脸也比较普通，没有 A 好认。

## 我们这边怎么做
- 文案（频道主写）→ 配音（MiniMax，主角的“温润男声”就合适）→ 按句子切成一张张图 → 字幕跟着配音冒出来。
- 照片：
  - MiniMax 生成写实照片；
  - 或者 Pixabay / Pexels 这类免费可商用的图，要密钥，或者频道主下载好发过来；
  - 或者频道主自己的照片。
  - 不用电影截图。
- 形象：`tools/catify/` 自动换头、涂皮肤。正脸、侧脸、手看得清的照片效果好；背影不行；浅色带花纹的衣服容易被误认成皮肤，挑照片时避开。
- 取景框：不照搬参考视频的“摄像机”框，做我们自己的（比如左上角一对橙青的猫眼 + “黑猫不说话”）。

## 频道主 10 月 28 日定的
- **形象用 B（猫耳毛线帽）**，不用白猫。女生用频道主发来的那个（`characters/读文案/`）：
  - 他：黑色猫耳毛线帽 + 白色圆脸、黑豆眼；
  - 她：猫耳毛线帽带粉色蝴蝶结、黑长直、白脸、腮红；
  - 别的人：白脸、深灰短发、不戴帽子。
  - 换到照片上的样子见 `形象_第二版.jpg`。
- **照片可以用图库**，但一定要**有人**：
  - 一个人、两个人或者几个人都行；
  - 要亲密的，或者有故事感的；
  - **不要没有人的风景照**（没人就没法换成我们的角色）。
- **取景框**用我们自己的：左上角一对橙青的猫眼 + “黑猫不说话”。

## 挑照片（`tools/catify/` 自动换形象，哪些照片换得好）
- 脸、手看得清的：正脸、侧脸都行。背对镜头的会画成背影（后脑勺），能用，但没有五官。
- 穿得多一点的好：露出来的只有手、脖子最干净。大片露出来的腿、肩膀会变成大块的白，容易漏涂、边缘不齐。
- 两个人抱得很紧、脸叠在一起的，常常分不清谁是谁，换完要一张张看，不行就换一张。
- 浅色带花纹的衣服容易被认成皮肤。

## 还没定的
1. 图库：Pixabay 要密钥（`PIXABAY_API_KEY`，在环境设置里加），Pexels、Unsplash 在这个环境里连不上。没有密钥时只能用 MiniMax 生成的写实照片，或者频道主发来的照片。
2. 配音用哪个声音（参考视频是低沉、平稳的男声，跟主角的“温润男声”差不多）。
3. 第一条的文案（频道主写）。
