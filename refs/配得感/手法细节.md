# 手法细节：《当一个男生的配得感越来越低》量出来的参数

总览见 `剖析.md`，每个镜头见 `分镜表.md`。这份是把能量化的东西都量出来，并写清楚在我们的引擎里怎么做。

**怎么量的**
- 画面：按每秒 10 帧和 30 帧抽出来，量锐度、亮度、饱和度、帧间差异。
- 声音：看波形和频谱（音高、起音、频段）。我听不到声音，声音部分都是推断。
- 时间误差约 0.03–0.1 秒。

## 1. 节奏

**镜头长度**
- 59 个镜头，平均 2.8 秒，中位数 2.5 秒；最短 0.9 秒，最长 7.2 秒。
- 长度分布：短于 2 秒的 20 个，2–3 秒的 15 个，3–4 秒的 9 个，4–6 秒的 12 个，6 秒以上的 1 个。

**每一段的快慢**：动情的地方慢，日常和来回对话快。

| 段落 | 时间 | 占全片 | 镜头数 | 平均每个镜头 |
|---|---|---|---|---|
| 钩子 + 想要的东西 | 0–5.7 | 3% | 4 | 1.4 秒（很快） |
| 第一次让（妈妈哭） | 5.7–22.5 | 10% | 5 | 3.4 秒（慢下来） |
| 第二到第四次让 | 22.5–69 | 27% | 16 | 2.9 秒 |
| 生日礼物（来回问） | 69–99 | 18% | 12 | 2.5 秒（最快的对话） |
| 回忆快闪 + 说出口 | 99–119.5 | 12% | 8 | 2.6 秒（快闪本身 4 秒 40 张） |
| 解释 + 安慰 | 119.5–161 | 24% | 11 | 3.8 秒（最慢、最暖） |
| 下单 + 字卡 | 161–170 | 6% | 3 | 3.2 秒 |

**对白**
- 约 59 句：儿子约 26 句，女朋友约 22 句，妈妈约 8 句，爸爸约 3 句。
- 每句很短，平均约 8 个字，说 1–3 秒。
- 句子之间停 0.3–0.8 秒。说话的时间约占全片一半。

**没有台词、只有音乐的地方**只有两处，都是情绪最重的时候：
- 38–46 秒（8 秒）：给妈妈挑项链，把自己的衣服从心愿单里删掉；
- 98–104.5 秒（6 秒）：回忆快闪，接那双球鞋。

## 2. 结构比例
- **问题靠重复演出来，占了将近四成（3–69 秒）**。四次“让”的长度：
  - 第一次 17 秒，第二次 24 秒，第三次 17 秒，第四次只有 6 秒；
  - 越往后越短，观众已经懂了，一句话带过就行。
- **追问三次，一次比一次重**：
  - 一个月前，随口问；
  - 一周前，又问；
  - “你把工作先停一停”，坚定地问。
- **转折点在 58%**（99 秒的回忆快闪），说出口在 62%，后面将近四成是解释、安慰和收尾。

## 3. 剧本里埋的线

**“应该”这个词是主线**
- 21 秒：*这是我应该做的；
- 118 秒：别应该了，就它了；
- 139 秒：如果我们总在做“应该做的事”。
- 先埋下，再翻过来，最后点明。

**数字**
- 进来的钱：工资 3000、客户 3000、爸爸 2000。
- 出去的钱：学费、项链 2340、房租。
- 给自己的：一直没有。1799 这个数出现了四次：开头的手机、心愿单、回忆最后一张、下单页面。

**同一个画面用两次**：第 3 个镜头（手机上的球鞋）在第 39 个镜头原样再出现，是彩色的，观众一下子就想起开头。

**“有用”**：他想的生日礼物全是“有用的”（电脑、耳机、给家里的电视），女朋友一句“都太‘有用’了吧”点破。

**视角交接**
- 前一半只有他的心里话（*这是我应该做的、*还算承担的起）。
- 74 秒起，女朋友的心里话出现了（*觉得奇怪、*突然发现自己并不知道他喜欢什么、*难怪一直都会觉得他很累），观众开始从她的眼睛看他。

**没有坏人**
- 妈妈劝他“留给自己花”，爸爸也给他转钱。两边都是爱，所以更让人难过。
- 问题出在他自己的“应该”上。

**“*”小字的分工**（约 35 条）：

| 用途 | 条数 | 例子 |
|---|---|---|
| 心里话（他和她都有） | 约 18 | *这是我应该做的、*还算承担的起 |
| 动作、情绪提示 | 约 10 | *抹眼泪、*认真、*坚定的语气 |
| 时间、背景 | 约 7 | *大四、*生日前一周 |

**标题公式**：当一个男生的 ___ 越来越 ___。写的是“一个过程”，观众会对号入座。

## 4. 转场

**模糊转场**（9 处：5.7、22.5、63.3、69.0、73.5、99.1、138.3、153.6 秒，开头进家门也是）
- **糊掉**：0.2 秒（约 6 帧），越来越快。
- **切**：在最糊的那一帧直接换成下一个画面，不叠化。
- **变清楚**：0.6 秒，先快后慢。整个转场约 0.8 秒。
- **用在**：时间跳跃（大四、工作以后、生日前一个月 / 一周），以及进出“讲道理”那段。
- **声音**：有几处配一声很低的“嗡”（5.6、63.5、138.4 秒）。

**叠化**（3 处）
- 手机特写 → 整屏截图（41 秒）、心愿单 → 阳光树叶（45 秒）：0.3 秒左右；
- 回忆最后一张 → 他的脸（104.6–105.1 秒）：0.5 秒。

**硬切**：同一场戏里换人说话，都是直接切。

## 5. 回忆快闪（99.0–105.1 秒），按帧拆开

| 时间 | 发生了什么 |
|---|---|
| 98.97–99.13 | 上一个镜头糊掉 |
| 99.17–99.63 | 5 张灰色画面，还是糊的，每张约 0.13 秒 |
| 99.67–99.80 | 白光（几乎全白）0.15 秒 |
| 99.87–101.60 | 约 25 张灰色画面，每张 1–3 帧（0.03–0.1 秒），每隔 0.2–0.4 秒夹一下白光 |
| 101.63–102.07 | 两张停得稍长（0.2–0.25 秒），比较暗 |
| 102.10–103.17 | 约 15 张，每张 1–2 帧，又有 3 下白光 |
| 103.17–103.27 | 最后一下白光 |
| 103.27–103.60 | 从白光里淡出彩色的球鞋（饱和度从 2 升到 39） |
| 103.60–104.60 | 停在彩色球鞋上 |
| 104.60–105.10 | 叠化到他的脸 |

- 画面都是片子前面出现过的（妈妈、项链、删衣服、转账、工资短信、生日……），顺序打乱。
- 灰色但留一点点颜色（饱和度约 10，彩色画面是 25–40）。
- **声音**：
  - 白光那几下配低音冲击，共 8 下：99.35、99.78、100.0、101.29、101.87、102.30、102.55、102.71 秒；
  - 进快闪前一声往上走的“嘶”（98.1 秒）；
  - 最后一下白光后留一个长音（103.5–105 秒）。

## 6. 镜头

**慢推**
- 3.6 秒以上、有人在说话的镜头，放大 4–10%，大约每秒 1.5%。
- 3 秒以下的镜头都不动。
- 讲道理的手画图也慢推（6–8%）。
- 结尾字卡推得最多：16%，4.3 秒。

**过肩**（7 个镜头）
- 前景的人：几乎是黑的、有点糊，占画面一侧的 35–45%，被画框切掉一部分。
- 后景的人：小，大约占画面高度的三分之一；清楚、亮。
- 用在“看着对方”“发现问题”的时候：妈妈抹眼泪、生日前一周她问他、她点破“都太有用了”之后他的反应。

**景深**
- 近景和特写时，背景的照片是虚的，人物清楚。
- 远一点的镜头背景清楚。

**动画很少**
- **口型**：说话时嘴在“闭（一条线）”和“张（一个深色小口）”之间来回换，每 2–4 帧换一次，大约每秒 4–7 次。
- **不眨眼**，身体也不动。
- 其他的动感全靠切镜头、慢推、手机里的界面动画。

## 7. 颜色：亮暗冷暖跟着情绪走

| 段落 | 亮度（0–255） | 饱和度 | 冷暖 | 情绪 |
|---|---|---|---|---|
| 开头：快餐店、球鞋 | 100–160 | 高（40–57） | 暖 | 想要的东西 |
| 回家，妈妈哭 | 60–140 | 很低（11–19） | 中性偏灰 | 压抑 |
| 大四、爸爸来电 | 100–150 | 中 | 暖 | 忙，但有家人 |
| 心愿单、下单这些界面 | 220–240 | 几乎没有 | 白 | 冷冰冰的数字 |
| 公园打电话（他） | 155–170 | 低 | 偏冷 | 离家远 |
| 妈妈在家接电话 | 140–170 | 中 | 暖 | 家 |
| 租房（新生活） | 180–205 | 很低 | 中性、干净 | 往前走 |
| 生日前一个月 / 一周 | 150–155 | 低 | 偏冷 | 心不在焉 |
| 点破、追问、说出口 | 165–195 | 中 | 暖 | 被看见 |
| 回忆快闪 | 不定 | 很低 | 偏冷 | 过去 |
| 讲道理（咨询师、手画） | 90–200 | 几乎没有（1–4） | 灰 | 另一个声音 |
| 安慰、谢谢你 | 185–195 | 中 | 暖 | 被爱 |

- 唯一一直是暖、饱和的东西就是那双球鞋。
- 整体比我们现在的“昏暗、昏黄”亮得多，只有回家那场是暗的。暗用在压抑的地方，不是全片都暗。**要不要学这一点，做的时候请频道主定。**

## 8. 字

**对话框**
- 字大：一个字约占画面宽度的 5%。在我们 1080 宽的画面上约 50–56 像素，我们现在用 34 像素，小了很多，手机上看会吃力。
- 一行最多约 11 个字，最多两行；框最宽能到画面宽度的 70%。
- 框没有尾巴，靠位置认人：
  - 压在画框的上边或下边，一半在画框外，靠近说话的人那一侧；
  - 电话那头的人放在画框顶上。
- 出现、消失都是 0.15 秒左右的淡入淡出。

**“*”小字**
- 一个字约占画面宽度的 4%（在我们的画面上约 42–45 像素），白色粗体，黑边。
- 放在相关的人旁边。
- 时间（*生日前一周）可以放在画框上方的黑边里。

## 9. 声音

**配音**

| 角色 | 音高（基频） | 声音 |
|---|---|---|
| 儿子 | 约 125 Hz | 年轻男声，平和 |
| 爸爸 | 约 100 Hz | 更低沉 |
| 妈妈 | 约 195 Hz | 中年女声 |
| 女朋友 | 约 230–280 Hz | 年轻女声，亮 |

- “*”字不配音。
- 纪录片那段由女朋友的声音念出来。
- 最后的字卡也不配音。

**配乐**
- 很轻的钢琴，像 G 大调。脉动是每 0.5 / 1 秒一下（约 60 / 120 BPM）；一个高音（约 D6，1170 Hz）一直在重复，下面是柔和的和弦。
- 只有音乐的地方比说话低约 12–13 dB（约 −26 dBFS 对 −13 dBFS）。
- 160 秒起换成另一段，调性像 E，更亮、更暖，有旋律，一直到片尾。
- 整片响度 −13.7 LUFS，响度范围 10.8 LU。

**音效**（都很轻，跟着画面里的动作走；能定位到的）

| 时间 | 声音 |
|---|---|
| 2.7 | 点手机屏幕，很短的“嗒” |
| 5.55 | 模糊转场的低音 |
| 5.9–6.3 | 门、钥匙（闷响加沙沙声） |
| 8.0 | 开灯“咔哒” |
| 19.5–21.0 | 消息弹出，发出、收到消息的提示音（带音高的“嘟”） |
| 23.0–23.4 | 键盘 |
| 25.0、26.5 | 到账提示音（客户、爸爸转账） |
| 98.1 | 进回忆前往上走的“嘶” |
| 99.35–102.7 | 回忆快闪的低音冲击，8 下 |
| 103.5–105 | 白光后的长音 |
| 115.5–116.3 | 3D 鞋子出现：低音加“唰” |
| 138.4 | 进灰色段的低音 |
| 141.4–141.7 | 笔在纸上 |
| 162–166 | 下单、付款成功、彩纸（被音乐盖住，量不出具体时间） |

- 没有一直铺着的环境声，底下垫的是音乐。

## 10. 在我们的引擎里怎么做（做之前的准备清单）

| 手法 | 做法 | 要不要频道主定 |
|---|---|---|
| 模糊转场 | 新写一个 `blurCut(t, 切的时间)`：前 0.2 秒模糊半径从 0 加到约 28 像素，越来越快；在最糊时换镜头；后 0.6 秒从 28 降到 0，先快后慢。做法跟 `warmGrade` 一样：把画框那块拷出来，加 `blur` 再画回去。加音效 `whoomp`（50–90 Hz 的低音，0.35 秒） | 不用 |
| 回忆快闪 | 用前面镜头的画面函数（像 talk11 的 `replay`），画的时候加 `grayscale(.9)`；按第 5 节的表排：先慢后快，夹白光，最后一张从白光淡出彩色。音效：低音冲击，最后一个长音 | 不用 |
| 口型 | 主人公：每个表情加一张张嘴的版本（在 `expressions.html` 里加 `open`）；其他角色：量出嘴的位置，说话时叠一个深色小椭圆。按配音的响度开合，每秒 5–6 次 | 不用 |
| 对话框 | 字放大到约 50 像素；可以选“压在画框边上、没有尾巴”；电话那头放顶上 | 要（换样式） |
| “*”小字 | 白色粗体加黑边，约 42 像素，放在人旁边；时间放画框上方 | 要（心里话用泡泡还是小字） |
| 过肩 | 后景的人缩到 0.55–0.65 倍；前景放另一个人，压到很暗（亮度 0.15）、糊 4 像素、放大到画面一侧 40%。主人公的背影用他的剪影代替（猫耳帽认得出来） | 不用 |
| 景深 | 镜头推近（放大到 1.3 倍以上）时，只给照片加 2–5 像素的模糊，人物不糊 | 不用 |
| 背景跟着机位换 | 一场戏用**一张很宽的照片**（2048×1024）：拍她时用左边，拍他时用右边，两人同框用中间。这样还是“一张图”，颜色光线一定一致 | 要（跟“一场戏一张图”的规矩有关） |
| 慢推 | 已有（`camLerp`）。3.5 秒以上、有人说话的镜头，每秒放大约 1.5%；短镜头不动 | 不用 |
| 手机界面 | 在现有的手机插入镜头上加：心愿单左滑删除（数量一件件少）、转账卡片、银行短信条、商品页、下单成功 | 不用 |
| 亮暗 | 按情绪选：压抑的场景暗，温暖的场景亮 | 要（跟“背景昏暗、昏黄”的规矩有关） |
| 配乐 | 很轻的钢琴，一个高音重复；只在没有台词的地方让音乐出来；结尾换一段更亮的 | 不用 |
| 姿势 | 打电话、摸头这类动作我们画不了。需要的话请频道主给图；不然用插入镜头（手机）和过肩来绕开 | 要（给不给新图） |
