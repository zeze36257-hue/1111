# 参考视频剖析：《当一个男生的配得感越来越低》

频道主发来的参考视频（2026-10-27），频道主说：“这种视频就是我对你的理想型”。

要学的是**分镜、运镜、背景调换、音效、剧情**；选题（男生配得感低、自卑）频道主也很喜欢，觉得是很大的社会现象。

- 这份是剖析，**还没有做视频**。做的时候频道主会再来找。
- 原视频没有存进仓库（是别的博主的作品）。以后要再看原片，请频道主再发一次。
- 更细的两份：
  - `分镜表.md`：59 个镜头逐个拆开（时间、景别、画面、台词、镜头运动、转场和声音）；
  - `手法细节.md`：量出来的参数（节奏、转场、回忆快闪逐帧、口型、颜色、字号、配乐、音效），以及在我们的引擎里怎么做。

## 一、先说结论
- **这是一条插画短剧**：
  - 平涂插画的人物，背景是做成画风的真实照片；
  - 画面放在竖屏中间，上下留黑。这跟我们现在的格式几乎一样。
- **剧情就一件事**：一个懂事的男生，钱永远先给别人。
  - 先是自己的学费，然后是妈妈的项链、妈妈的生日，最后是女朋友想租的房子；
  - 自己想要的那双球鞋，一拖就是好几年。
  - 最后女朋友发现了，逼他说出自己想要什么，让他自己下单。
- **它好看的原因**：
  - 不讲道理，一次次“让”给观众看；
  - 嘴上说的和心里想的有反差；
  - 一个小物件（球鞋）从头串到尾；
  - 数字会说话（工资 3000、项链 2340、球鞋 1799）。
- **其实是“得物”的广告**：
  - 台词里点名“得物”，这两个字用品牌色；
  - 结尾是在得物上下单、付款成功、品牌 logo。
  - 我们做的时候不需要这一层。

## 往深里看以后的新发现（细节见 `手法细节.md`）
1. **“应该”这个词是主线**：
   - 21 秒：*这是我应该做的；
   - 118 秒：别应该了，就它了；
   - 139 秒：如果我们总在做“应该做的事”。
   - 先埋下，再翻过来，最后点明。
2. **同一个画面用两次**：开头手机上的球鞋（第 3 个镜头）在回忆快闪的最后原样再出现，而且只有它是彩色的。
3. **视角交接**：前一半只有他的心里话；74 秒起女朋友的心里话出现，观众开始从她的眼睛看他。
4. **快慢跟着情绪走**：
   - 妈妈哭、安慰他这两段最慢（平均每个镜头 3.4–3.8 秒）；
   - 来回追问最快（2.5 秒）；
   - 只有两处没有台词，都是最难过的时候。
5. **人物几乎不动**：只有说话时嘴一张一合（每秒 4–7 次），不眨眼。动感全靠切镜头、慢推和手机界面。我们给角色加口型就能做到。
6. **模糊转场的做法**：0.2 秒糊掉，在最糊时换镜头，0.6 秒变清楚。
7. **回忆快闪是有节奏的**：先慢后快，夹着白光和低音冲击，最后从白光里淡出那双彩色的球鞋。
8. **字比我们大得多**：对话框的字约占画面宽度的 5%（我们 1080 宽的画面上约 50–56 像素），我们现在只有 34 像素。
9. **整体比我们亮**：只有回家那场是暗的；暖的颜色只给“爱”和“想要的东西”。

## 四、叙事手法（最值得学的）
1. **同一个动作重复四次，每次换一个人**：
   - 自己的学费 → 妈妈的项链 → 妈妈的生日 → 女朋友的房租。
   - 不用解释，观众看到第三次就开始心疼。
   - 每次都比上一次短，节奏越来越快。
2. **一个小物件串起全片**：那双 ¥1799 的球鞋。
   - 开头出现，中间被忘掉；
   - 回忆快闪的最后一张是它（彩色）；
   - 结尾终于买下。首尾呼应。
3. **让数字讲故事**：
   - 工资 3000、转账 2000、项链 2340（原价 2599）、球鞋 1799；
   - 心愿单 9 → 8 → 7、心愿单里 16 件。
   - 观众自己会算：他给别人花的，比给自己的多得多。
4. **嘴上说的和心里想的反差**（这正是我们频道要的）：

   | 嘴上说的 | 心里想的 |
   |---|---|
   | 我已经吃了 | *这是我应该做的 |
   | 放心不贵 | *你们开心我就开心 |
   | 贵点就贵点 | *还算承担的起 |
   | 都行吧 | *还真没想过 |

5. **问题由另一个人发现**：
   - 女朋友视角的一句“*突然发现自己并不知道他喜欢什么”，比主人公自己说出来更动人。
   - 她不是讲道理的“学姐”，是心疼他的人。
6. **讲道理的部分很短**：
   - 只有约 15 秒；
   - 借女朋友转述纪录片，不是主人公或旁白在说教；
   - 画面换成灰色和手画图，跟剧情分开，讲完马上回到两个人身上（摸头、“辛苦你了”）。
7. **时间跳跃靠小字加模糊转场**：“*大四”“*工作后有了女朋友”“*生日前一个月”“*生日前一周”。一句话交代清楚，不拖。
8. **高潮前留一个问题**：
   - “你想要什么？”这个问题对别人很简单，对他很难；
   - 回答不出来的那几秒，就是情绪最重的地方；
   - 接着是回忆快闪，然后才说出“那双科比”。

## 五、分镜和运镜

**景别**
- **近景 / 特写最多**：脸占画面一半以上。大部分对话都是近景。
- **过肩镜头**：前景是一个人的背影或肩膀（暗的、糊的），后景是另一个人。用在“看着对方”“发现问题”的时刻：
  - 9 秒：他的背影，后面妈妈在抹眼泪；
  - 74 秒：他在电脑前的背影，后面女朋友坐在床上问他；
  - 87、124 秒：从她的肩膀后面看他。
- **双人镜头**：两个人同框，用在关系最近的时候。例如 131–138 秒，她摸他的头。
- **插入镜头**（约 9 个）：
  - 拿着手机的手（手指在滑）；
  - 整屏的 APP 截图（心愿单左滑删除、下单页面）；
  - 聊天、转账卡片、银行短信从画面边上弹出来。

**正反打**
- 对话时在两个人之间来回切，换人说话就切一次。
- 打电话时两边各在自己的地方：他在公园，妈妈在家里的沙发上。

**运镜**
- 短镜头（1.5–3 秒）都是**固定**的。
- 长一点的对话镜头（4–7 秒）几乎都有**很慢的推近**，放大 5–10%，大约每秒 1.5%。例如：
  - 11–17 秒，妈妈抹眼泪：放大 10%；
  - 54–61 秒，妈妈打电话：8%；
  - 126–131 秒，女朋友说“你还看得见他”：8%；
  - 143–153 秒，讲道理的手画图：6–8%。
- 没有大幅度的摇、移；动感来自切镜头、手机里的滑动和弹出的元素。

**颜色**
- 现实是彩色，回忆和讲道理是灰色。
- 回忆快闪的最后一张回到彩色（那双鞋），用颜色告诉观众“这才是他真正想要的”。

## 六、背景和转场

**背景**
- 背景是真实照片做成画风，像描过边、色块化。近景时背景虚化，有景深；人物是平涂插画。
- **背景跟着机位换**：
  - 同一个房间里，镜头从这边拍和从那边拍，背景是房间的不同面：
    - 女朋友身后是白色柜子；
    - 他身后是蓝色窗帘和空调；
    - 两人的全景能看到电脑桌和床。
  - 颜色、光线一致，看得出是同一个房间。
- 开场和过场用**真实照片 / 视频**：
  - 开头的快餐店柜台；
  - 45 秒的阳光穿过树叶，交代“时间过去了”。

**转场**

| 转场 | 用在哪 | 做法 |
|---|---|---|
| **模糊转场**（用得最多） | 时间跳跃：5.7、22.5、63、69、73.5、99、138、153 秒 | 上一个画面 0.2 秒糊掉，在最糊时换镜头，下一个画面 0.6 秒变清；有几处配一声很低的“嗡” |
| 叠化 | 手机特写 → 整屏截图；心愿单 → 阳光树叶 | 两个画面交叠淡过去 |
| 硬切 | 同一场戏里换人说话 | |
| 快闪 + 白光爆闪 | 回忆（99–103 秒） | 每张 0.2–0.3 秒，灰色，中间几下白光；最后停在彩色的球鞋上 |
| 3D 翻转 + 彩纸 | 付款成功（164 秒） | 品牌的下单效果 |

## 七、声音
（我听不到声音，下面是看波形和频谱推断的：说话的音高、时间点，音乐和音效的形状。）

**配音**
- 每句对白都配。四个声音分得很开：
  - 儿子：年轻男声，音高约 125 Hz；
  - 爸爸：更低沉，约 100 Hz；
  - 妈妈：中年女声，约 195 Hz；
  - 女朋友：年轻女声，约 230–280 Hz。
- 带“*”的小字不配音。
- 纪录片那段是女朋友的声音读出来的，不另外找“专家”的声音。

**配乐**
- 很轻的钢琴 / 铃音：一个高音大约每 1.5 秒重复一次，下面是柔和的和弦；从头垫到尾。
- 不说话的段落只剩音乐（38–46 秒挑项链、删衣服），比说话低约 12 dB。
- 结尾（160 秒起）换成更暖、带旋律的一段，一直到片尾。

**音效**（都很轻，跟着画面里的动作走）
- 回家：开门的闷响、开灯的“咔哒”（6–8 秒）；
- 发消息的“嘟”、打字的键盘声、到账提示音（20–25 秒）；
- 每次模糊转场一声“嗖”和一点低音；
- 回忆快闪时一记很响的“唰”、爆闪（100.5 秒，全片最响的一下）；
- 付款成功的庆祝音效。

## 八、字幕和画面元素
- **对话框**：
  - 白色椭圆，没有尾巴，粗黑字；
  - 压在画框的上边或下边（一半在画框外），靠近说话的人；
  - 电话那头的声音（画外音）放在画框顶上。
- **“*”小字**：白色粗体加黑边，放在相关人物旁边，有三种用途：
  - 心里话：*这是我应该做的、*还算承担的起；
  - 动作和情绪提示：*抹眼泪、*认真、*坚定的语气、*疑惑、*感动、*辛苦你了；
  - 时间和背景：*大四、*兼职外包中、*生日前一周。时间也可以放在画框上面的黑边里。
- **手机画面**：
  - 用真实的 APP 界面（购物页、心愿单、转账、银行短信），观众一看就懂；
  - 价格、数量这些数字要看得清。

| 人物姿势 | 每个镜头都画新姿势：打电话、拿手机、摸头 | Wojak 角色是固定的半身像，只能换表情 | 用插入镜头（手机屏幕）、过肩镜头（前景放一个人的暗背影）、镜头推近来补；要打电话、背影这类姿势，需要频道主给图 |
| 背景 | 跟着机位换，同一个房间的不同面 | 一场戏一张图（频道主定的） | 如果要学，同一场戏可以准备同一个房间的两三个角度（光线、颜色一致），正反打时各用各的。**这跟之前的规矩不一样，做的时候请频道主确认** |
| 运镜 | 长镜头慢推（每秒约 1.5%） | 已经有（talk10、talk11 的 `camLerp`） | 照用；短镜头保持固定 |
| 过肩镜头 | 前景的人是暗的、糊的 | 没做过 | 前景放另一个角色的剪影（`talk11` 的 `passers` 那种黑影），糊一点 |
| 转场 | 模糊转场为主 | 黑场为主 | 加一个“模糊转场”：上个画面糊掉，下个画面从糊变清，配“嗖” |
| 回忆 | 灰色快闪 + 白光爆闪，最后一张彩色 | 泛黄 + 颗粒（talk10）；快放（talk11） | 加“灰色快闪”：去色、每张 0.2–0.3 秒、白光；最后一张用彩色点题 |
| 配音 | 每个角色一个声音；“*”字不配 | 一样 | 照用 |
| 节奏 | 平均 3 秒一个镜头，2 分 50 秒 | 慢节奏，2 分钟左右 | 镜头可以切得更勤，重要的地方再留白 |

## 十、如果用这个选题做一期（先记下来，做的时候再定）
- **不照抄**：
  - 换掉球鞋、得物这些具体东西，换掉“学费、项链、房租”这串事；
  - 用我们自己的角色和日常（工作、家人、朋友）。
- **可以保留的骨架**：
  - 一个想要的小东西，一拖再拖；
  - 钱 / 时间先给别人三四次，每次更短；
  - 一个心疼他的人发现问题，问他“你自己想要什么”；
  - 回答不出来，回忆快闪，最后说出口；
  - 结尾他第一次为自己花钱 / 花时间，一句温暖的字卡。
- **角色**：
  - 主人公就是小黑；
  - 家人、女朋友这类角色，现有的 18 个人里没有，需要从办公室同事、6 个男生里挑，或者请频道主给新形象；
  - “发现问题的人”也可以是室友、老同学阿杰（`蓝卫衣男`）。
- **讲道理那段要核对**：原片说“总做应该做的事会把自己工具化，自我异化会引出抑郁这类情绪问题”，出处只说是“一个心理咨询的纪录片”，没核对过。
  - 要用的话，先查有出处的说法，比如：
    - 卡伦·霍妮讲的“应该”的暴政、自我疏离；
    - Higgins 的自我差异理论：现实的自己和“应该成为的自己”差得远，跟焦虑、不安有关。
  - 核对不到的就不说，或者说“可能”。
  - “配得感”是网络说法，不是学术名词，用的时候别说成研究结论。
