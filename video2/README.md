# 《其实，没人在看你》第二版（参考视频风格）

1080×1920、30fps，110.5 秒。仿照参考视频的做法：俯视镜头、深色留白、主角用橙色光环标出、左下角衬线字幕、用数字讲故事、时间标签（08:12 / 21:30 / 02:00 / 2000），没有配音。画面节点卡在背景音乐的段落上：17.25 秒音乐全编制进入时切入正片，89.5 秒音乐回落时进入金句。

| 文件 | 用途 |
| --- | --- |
| `index.html` | 动画源码；同目录放 `bgm.m4a` 后用浏览器打开即可边听边看 |
| `export.cjs` | 逐帧导出 MP4 / 抽检查帧（同第一版） |
| `fetch_fonts.py` | 下载页面用到的字体子集 |
| `聚光灯效应_v2.mp4` | 成片（含背景音乐，响度 -14 LUFS） |
| `聚光灯效应_v2_手机预览.mp4` | 压缩预览版 |

背景音乐取自参考视频的音轨，版权属于原作者，因此单独的音频文件没有放进仓库。

## 重新生成

```bash
export NODE_PATH=$(npm root -g)
ffmpeg -i <参考视频> -vn -c:a copy bgm.m4a
ffmpeg -y -i bgm.m4a -t 110.5 -af "afade=t=out:st=107:d=3.5,loudnorm=I=-14:TP=-1.5" bgm_cut.wav
node export.cjs --workers 4 --audio bgm_cut.wav --out 聚光灯效应_v2.mp4
```
