# 《她说·她想》样片：她说“我没事”

频道主问“这类视频具体是什么样的”，所以做了这条样片给他看（新体系见 `../refs/新体系/方案.md`）。

- **剧本**：我写的（方案里的例子）。
- **画面**：先拿现有的成图代替：16 草地、01 他回头、11 咖啡馆、17 拥抱。
  - 正式做的时候，换成他和她的表情包放在场景里（`../refs/新体系/表情包提示词.md`）。
- **两个声音**：
  - 他：温润男声 `Chinese (Mandarin)_Gentleman`；
  - 她：`Chinese (Mandarin)_Sweet_Lady`（No.55 的女朋友也是这个）；
  - 都是 0.95 倍速。
  - “……”的读法：他的台词里换成 `<#0.35#>`（MiniMax 的停顿），停一下再说；她的台词在开头，直接去掉。
- **字幕**：嘴上说的白字；心里想的淡蓝字（`#a9dcff`），加括号。
- **结尾**：黑猫写的一句（`ENDLINE`），不配音。一对橙青的猫眼眨一下，两行宋体字浮出来，后面压一条暗带。
- **背景音乐**：样片里垫了《Memories》，只为让他看个样子。正式发的时候成片不带音乐（`"music": {"off": true}`），他在抖音曲库里加。

## 做法
- `layout.py`：`SCRIPT` 每一项是 `[图, 谁, say/think, 台词, 停顿]`，`END` 是黑猫那句。
- 其余跟 `../wen04/` 一样：
  1. `python3 layout.py --prov`；
  2. `python3 ../tools/cine/tts.py .`；
  3. `python3 layout.py`；
  4. 接上画面代码。

```
NODE_PATH=$(npm root -g) tools/make_cine.sh shuo00 她说她想_样片_我没事.mp4
```
