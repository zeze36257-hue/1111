# 黑猫不说话 No.53《很久没联系的老朋友》

第一期**慢节奏、用镜头讲故事**的 Wojak 短剧（频道主要求，No.53 起）。人物、对话框、配音的写法照着 `talk08/`、`talk09/`，新的地方如下。

## 镜头（`scenes.js`）
- **机位**（`CAM_KEYS` / `camAt`）：
  - 每个关键帧写成 `[时间, 焦点 x, 焦点 y, 放大倍数]`。两帧时间挨着（小于 0.02 秒）就是**切**，隔得远就是**慢慢推/拉**。
  - 镜头同时作用在照片和人物上（在画框里先 `translate/scale` 再画）。
  - `drawShot` 返回的头顶、脸、猫的位置已经换算成镜头后的坐标，对话框的尾巴照样对得上。
- **插入镜头**（`INSERTS` / `phone`）：手机画在画框中间，后面压暗，有四种画面：
  - 朋友圈（配图是 `boxes.jpg`）；
  - 聊天记录：往上翻、翻回来，输入框里打字又删掉；
  - 锁屏通知：手机振动时画面跟着抖；
  - 新消息一条条冒出来。
  - 聊天记录内容在 `OLD`（从 2020 年到 2024 年）和 `NEW` 里。
- **转场**（`blackCards`）：段落之间先黑场，中间出时间字卡（“六年前”“现在”），换照片就在黑场里直接切。开头左上角有“晚上十一点半”。
- **回忆**（`memoryLook`）：用 `warmGrade()` 让整个画面泛黄，再加一点闪烁、灰尘和划痕。只有回忆这段这样调。
- **手机的光**：看手机的时候，脸上有一点冷白的屏幕光（`PHONE_LIT`）。
- **消息台词**：`DIALOG` 里 kind 是 `msg` 的台词显示在手机里，有配音、不出对话框。插入镜头挡在前面时，对话框不画尾巴。
- **表情**：`HX` 是每句开始时换的表情，`EXTRA` 是台词之间另外换的（“在吗？”之后从愣住变成笑出来）。

## 时间轴（`layout.py`）
- `LEAD0`：开头空 7.2 秒，给空镜、人物出现和朋友圈。
- 打字又删掉的时间写在停顿里：`TYPE1()`、`TYPE2()` 接在台词结束之后。
- 换段写成 `(段名, pad, lead)`。
