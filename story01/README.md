# 动画讲故事 第 1 集：荒野猎人的真实原型（休·格拉斯）

11 月 5 日做的。16:9，1920×1080，30 帧，约 4 分 44 秒。稿子和核对情况见 `refs/讲故事/第1集_荒野猎人.md`。

## 怎么做的
1. **旁白**：`tools/voice/narrate.py refs/讲故事/第1集_荒野猎人_旁白.txt <目录> --speed 0.86`
   - 声音是音色设计 1 号“温和自然”（`ttv-voice-2026110508401026-kAVaXtXg`）。
   - 语速：1.0 倍时每分钟 333 字，比参考视频（281 字）快将近两成，所以用 0.86 倍。
   - 结果存成 `narration.m4a`、`narration.srt`，全长 279 秒，其中留白 82 秒。
2. **人物设定图**（`img/ref_*.jpg`）：格拉斯、菲茨杰拉德、布里杰（`ref_bridger2`；第一版浣熊帽太卡通，没用）。后面有人物的镜头都把设定图当参考图传进去，人物就是同一个人。
3. **分镜**：`shots.py`，52 张图、9 段动画、64 个镜头（含段落之间的黑场）。
   - 画面是画面，话是话：镜头大多切在旁白的留白里。
4. **出图、做动画**：`python3 gen.py images`、`python3 gen.py clips`。
   - 出图：Seedream 5.0 flash，2560×1440，3 张一起，52 张大约 5 分钟。
     - 第一遍有 5 张不对，改提示词重画：好几个人都戴主角的红围巾、人披熊皮像被熊抱着、熊头人。旧图在 `img/_old/`（不进仓库）。
   - 动画：Seedance 2.0 mini，720p，4～9 秒，每段 1.5～3 分钟。
5. **配乐和环境声**：`python3 music.py` → `bgm.wav`。全部用 numpy 合成：拨弦吉他、低音铺底、心跳、风、篝火、河水、雨和雷、熊吼和闷响。
6. **出片**：`python3 render.py`
   - 慢运镜：每秒放大或平移 1.2% 左右，频道主说慢一点有沉浸感。
   - 转场：同一段里的镜头 0.5 秒叠化，段落之间黑场；熊扑上来那一下是白闪加三道爪痕。
   - 字幕：按标点切成短句，放在进度条上面。
   - 进度条：`tools/story/progress_bar.py` 的 `Bar`，一条线加仙人掌柜。
   - 声音：配乐在旁白说话时自动压低，整体响度 -16 LUFS。
   - 检查画面用 `python3 render.py --frames 5,86,210`。

## 不进仓库的
- `img/_old/`、`frames/`、`bgm.wav`、`final_audio.wav`：能重新生成。
- 旁白的 wav 在会话的临时目录里，仓库里是 `narration.m4a`。`render.py` 找不到 wav 就用 m4a。
