## 音乐：原创配乐（`music.py`），A 小调 → C 大调

75 BPM，1 小节 = 3.2 秒。开头每一拍一声很轻的高音“滴答”（等消息）和一段 A 小调的小旋律；警报那段底下有心跳，报警器响时变快；
没人理的那几小节同一个音反复、越来越紧，再被 G 拉向 C；最后一段转 C 大调，开头的旋律换成小提琴、往上走，“只是太怕失去”在最高处。
