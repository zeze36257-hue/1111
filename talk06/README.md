# 黑猫不说话 · 心理学 No.50《高敏感人群：不是你太敏感，是你感受得更多》

第一期**真实照片 + 黑猫 + 对话框**。从这一期起，频道转型做这种视频，以前的讲课、动画格式不再做。

## 怎么做的

**画面**
- 一个宽画框 `FR`（1080×960，y 470–1430）放在竖屏中间，上下留黑，像参考视频那样。
- 画框里放照片（`photos/`），每个镜头是一张照片，用裁切框 `[x, y, w]` 慢慢推拉。
- 镜头之间交叉淡化 0.7 秒。学姐那一段的镜头会跟着说话的那只猫走。

**黑猫**
- 画在照片坐标里，所以会跟着照片一起推拉。
- 每只猫有接触阴影，轮廓里混进一点场景的光色。
- 小黑是品牌黑猫：左眼橙、右眼青（`catP` 分左右两半画）。

**对话框**
- 说出口的话用白色椭圆，尾巴指向说话的那只。
- 心里想的用淡蓝的泡泡，尾巴是三个小圆点。
- 说话的角色不在画面里时，对话框贴在画框右上角，标上名字。

**配音**
- 每个角色用自己的声音（`meta.json` 里的 `voices`）。
- `tools/cine/tts.py` 支持 `DIALOG` 里的台词，`tools/cine/audio.py` 会把每句的响度拉到一样，心里想的那几句稍轻一点。
- 没有旁白，所以 `LINES` 是空的。

**讲知识**
- 在画框里叠小图示：1/5、过载、大脑、双胞胎、天生的特质、糟糕/好的环境、充电、日程。

**时长**：正片 153.6 秒，加片尾约 2 分 36 秒。没有片头，片尾和水印保留。

**对白和引用**：都在 `文案.md` 里。

## 出片
```
MUSIC_ASSETS=<乐器采样目录> NODE_PATH=$(npm root -g) tools/make_cine.sh talk06 高敏感人群_No50.mp4
```
改台词：先改 `layout.py` 的 SCRIPT，再依次运行 `python3 ../tools/cine/tts.py .` 和 `python3 layout.py`，然后出片。

## 声音
- **配乐**（`music.py`）：B 小调 → D 大调。
  - 街上同一个音飞快地反复；
  - 老板那句之后几乎没声音；
  - 晚上是八音盒；
  - 学姐来了之后变暖；
  - 第二天早上，小提琴把八音盒的旋律接过来往上走，最后停在 D 大调。
- **音效**：街上的人声车声（`crowd`）、汽车喇叭（`honk`）、公园的鸟叫（`birds`）。这三个是这一期新加到 `tools/cine/audio.py` 里的。
