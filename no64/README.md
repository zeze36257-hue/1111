# 黑猫不说话 · No.64《三关测试：你的眼睛在骗你》（真人出镜 · 试播）

第一期真人出镜的试播：频道主自己出镜、自己说，动画配合主持人。电影感引擎（`../tools/cine/`），这一期用自己的 `render` 覆盖了引擎的（不加泛光、暗角、颗粒和旁白字幕：错觉画面的像素值不能被后期改动）。

- **时长**：72 秒（底版）。没有片头，第一帧就是封面；片尾卡在正片里（67.6 秒起）。
- **出片**：`bash no64/make.sh`，出两个文件：
  - `你的眼睛在骗你_No64_底版.mp4`：成片的底。上半屏（y 360–1170）是动画，下半屏（y 1250 以下）空着，留给主持人的画面；音乐和音效已经压到垫在人声底下的音量（−24 LUFS）。
  - `你的眼睛在骗你_No64_提词版.mp4`：录制时用。静音；前面多 3 秒倒数；下半屏显示当前这句台词（逐字走色）、动作提示和下一句；右上角是底版时间。
- **字幕**：底版不压旁白字幕。主持人录完以后，用剪辑软件按自己的声音自动识别字幕（说的就是字幕，最口语、也最对得上口型），放在动画和人之间（y 约 1170–1250）。
- **怎么剪**：底版放主轨；主持人的视频放画中画，摆在下半屏（可以用“智能抠像”把背景抠掉，人就站在暖色的顶光里）；把主持人说第一句“三关测试”的地方对到底版 0.2 秒。之后只要录的时候跟着提词版走，就基本对得上；个别地方可以把主持人的片段切开挪一挪。

## 三关

1. **第一关 · 大小（3.0–12.0）**：艾宾浩斯错觉（Ebbinghaus illusion，也叫铁钦纳圆）。两个一样大的橙色圆，左边围着六个大圆、右边围着八个小圆，右边看起来更大。10.5 秒：周围的圆飞走，两个橙色圆并排，两条虚线贴着上沿和下沿：一样大。
2. **第二关 · 明暗（12.0–27.0）**：棋盘阴影错觉（checker shadow illusion，Edward H. Adelson，MIT，1995）。6×6 的棋盘斜着看，绿色圆柱的影子往左下拖。亮格 204、暗格 120，影子是乘法 150/255，所以影子里的亮格 B = 204 × 150 / 255 = 120 = 阳光下的暗格 A。19.5–21.0 秒两根同样是 120 的灰条从 A 长到 B；21.8 秒起其余全部淡出，只剩 A、B 和灰条。24 秒棋盘回来，影子描一圈虚线：“大脑自动‘扣掉’了影子”（视觉系统会把光照的影响折算掉，按“表面本来的颜色”来判断：B 在影子里还这么亮，那它“本来”一定是白格）。
   - 自检：`node <脚本> no64` 在第 14、17、19、20.5、22.5、23.5 秒读 A、B 中心和边上的像素，全部是 (120,120,120)。
3. **第三关 · 颜色（27.0–54.0）**：负后像（negative afterimage）。同一张画（天空、太阳、气球、房子、树、草地上的黑猫）画两遍：盯的那张是“反色”（每种颜色亮度不变、色相取相反：蓝天变橙色、绿草变紫色、红屋顶变青色），换成黑白图（只剩亮度）的那一刻，眼睛自己补出原来的颜色，几秒钟后慢慢消失。注视点在 (540, 770)，两张图里位置一样；30.8–48.0 秒注视点外有一圈进度，每拍一声钟表的滴答，最后五拍主持人倒数。盯的时候舞台上什么都不动。
   - 说法是简化的：“管颜色的细胞会‘累’”指视网膜上的视锥细胞（以及后面的颜色对立通路）盯久了会适应、反应变弱，换成没有颜色的图时，被“累”到的那一路弱下去，看起来就偏向相反的颜色。

结尾（60.0–67.6）：一只眼睛，“你看到的，不全是真的”“是大脑帮你‘猜’的”（措辞留了余地：知觉是大脑根据输入做出的推断，不是照相）；然后“你第几关被骗了？”三个关卡标签 + “评论区告诉我”。片尾卡：黑猫睁眼，“关注 @黑猫不说话”“带你看更多大脑的 bug”，最后闭眼。

## 音乐：原创配乐，从头到尾不断

D 大调，80 BPM，1 小节 = 3 秒（`music.py`）。轻快的“魔术”感，垫在人声底下：竖琴和短促的钢琴在人声音区之下和之上，几乎没有旋律落在人声的音区。

- **开场**：魔术动机 D–A–升 G–A（升 G 是利底亚音阶的特征音），竖琴加高音钢琴。
- **第一关、第二关**：拨弦式的律动（低音在一、三拍，弱拍上是短促的高音和弦）；两次揭晓（10.5 秒、21.0 秒）都落在拍点上。
- **第三关·盯点**：律动停下，长音的弦乐一小节爬一级，每拍一声钟表；最后两小节是升 F 大调（B 小调的属和弦），配合倒数。
- **换成黑白（48.0）**：打开到 D 大调（利底亚），竖琴滑奏，音量只抬一点（主持人这里是小声说话）。
- **原理、结尾**：律动回来；片尾一个 D 大调和弦。
- **混音**：配乐 −14 LUFS，加上音效后整体再降 10 dB（−24 LUFS），作为人声的垫底音量。各段的响度差控制在几 dB 以内（LRA 约 5），不会突然盖过人声。
- 取样器里的竖琴只有一层录音，力度参数不起作用；`music.py` 里的 `harp()` 按力度换一个音量不同的同一把竖琴。
