# 黑猫不说话 · 心理学 No.49《恐惧型依恋：越想要，越推开》

恋爱心理系列第四期（前三期：talk02 回避型、talk03 焦虑型、talk04 焦虑型配回避型），也是第一期**情绪短剧**风格。目录叫 talk05，因为 no49/ 已经被以前没发的那期占了。

## 和前几期不一样的地方

- **先讲故事，后讲知识**：前 38 秒只讲一只猫的一个晚上和第二天早上，心理学放在最后 30 秒。
- **画面更大、场景更具体**：
  - 猫放大到原来的 3 倍，占半个屏幕；
  - 场景是下雨的窗、手机、门、伞、门缝下的光，不再是星空里的示意图。
- **配音慢一点**：还是温润男声，语速 0.92（meta.json 里 `"speed": 0.92`）。
- **更短**：正片 70.4 秒，加片尾约 73 秒。

## 不变的地方

- 没有片头，第一帧就是封面“他说想你，我只回了一个‘嗯’”；片尾和水印保留。
- 角色都是黑猫，用的是同一个 `fig()`。主角用 `cat2()` 画两遍、各裁一半：左边暖橙，右边冷蓝，左眼橙、右眼蓝。

## 文件和步骤

- **文案**：`文案.md`。
- **出片**：`tools/make_cine.sh talk05 恐惧型依恋_No49.mp4`。
- **改文案**：
  1. 改 `layout.py` 里的 SCRIPT；
  2. 运行 `python3 ../tools/cine/tts.py .`；
  3. 运行 `python3 layout.py`；
  4. 出片。

## 声音

- **配乐**（`music.py`）：G 小调 → 降 B 大调。
  - 夜里是慢钢琴加八音盒的旋律；
  - 他来到门口时有紧张的心跳；
  - 门关上的那一小节几乎没有声音；
  - “它不是不想被爱”那里，小提琴把夜里的旋律接过来；
  - 最后用小提琴在降 B 大调上往上走，以降 E → 降 B 结束。
- **雨声**：用的是新加在 `tools/cine/audio.py` 里的 `rain` 音效。
  - 隔着窗户、隔着门时是闷的（`muffle`）；
  - 门开着时听得清楚。
