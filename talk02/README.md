## 音乐：原创配乐（`music.py`），从头到尾不断

75 BPM，1 小节 = 3.2 秒，各段从小节线开始（段落位置读 `timeline.json`）。

- **前四段 D 小调**，冷而克制：开头一段高音钢琴的小旋律；题目在 G 小调上抬起、停在 A。
- **一层壳**：钢琴先只剩每拍一个音（冷）；宝宝那段两声八音盒；心跳交给音效（和画面上的心电图同一张表，一拍不差）。
- **怎么来的**：压下去的那两小节最安静；分心时同一个音反复、越来越紧；反弹时竖琴一串往上，转到 B-flat、C。
- **怎么办转 F 大调**：开头的旋律换成小提琴回来，从往下走变成往上走；“只是爱得很小心”在最高处；最后一个 F 大调和弦。
- **混音**：配音时配乐自动压低约 10 dB；整段 −14 LUFS。
